# 風の軌跡

位置 P=(x,y) の時間微分を F(P)=(dx/dt,dy/dt) とする。右が x の正、上が y の正。回転 (−ωy,ωx)、内向き渦 (−ax−ωy,ωx−ay)、吸い込み (−ax,−ay)、噴水 (ax,ay)、鞍点 (ax,−ay) を切り替える。回転のみでは半径は一定であり、原点は全モデルで停止点である。鞍点では x 方向に離れ、y 方向に近づく。

JavaScript の倍精度で、Δt=0.02 の RK4 を t=12 まで事前計算する。領域 [−5,5]² の外または非有限値で計算を終了し、最後の範囲内の標本まで描く。フレーム間隔や再生速度は数値解を変えない。初期点は3つの円に各16点、追加は16点まで。矢印の長さは速度×0.18、上限0.65座標単位。有限標本を結んだ描画であり、厳密な連続軌跡や実際の流体ではない。係数範囲は製品上の制限。

## 検証

Vitest は t=1 の解析解（指数関数と三角関数）と比較する。許容差は小数7桁で、刻み0.02の RK4 の大域誤差 O(Δt⁴) と画面の小数3桁表示に対して十分小さい。原点、入力のアンダーフロー、座標変換、固定種点、領域外と非有限値も検証する。Playwright は Chromium と Windows WebKit で操作と画面幅を確認する。

実機 iPhone Safari、スクリーンリーダー、低性能端末、長時間の熱・電池負荷は未検証。Windows WebKit は iPhone 実機ではない。

## 初回依頼との差分・残課題

記号選択は x・y 軸、速度矢印、観察値と係数入力の強調、および説明に対応するが、a・ω の図中の個別強調、数式内の直接選択とホバー選択は未実装。記号ボタンのクリック／タップとキーボード操作は利用できる。これらは今回未着手の残課題で、マウスを載せただけでは強調されない。式は既存の安全な MathML レンダラーを使い、文字列として表示する。教材は同じ操作画面を用い、1粒の段階で描画対象を1本に絞る。200%文字・DPR 2を含む全組合せの目視確認は未実施。
