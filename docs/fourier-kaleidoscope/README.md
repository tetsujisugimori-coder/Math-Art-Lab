# 010 · フーリエの万華鏡

作品メニューで「010」を選択。回転を足すと複雑な輪郭を組み立てられることを、図・操作・数式から観察する。初期は魚、K=16、停止、参考輪郭と円・腕ON。

## 数学規約

内部は上が正の数学座標、z=x+iy。複素数は「平面の横と縦を一組で表す書き方」。iで横と縦を区別し、回転と足し算を一つの式にする。

1. 閉じる辺を含む弧長でほぼ等間隔に128点を置く。末尾に始点を重複させない。重複頂点・ゼロ辺は無視し、全長0・非有限・2点未満は拒否する。
2. 標本の平均を引き、最大標本半径を1にする正規化は輪郭ごとに一度だけ。DFT自体は中心や尺度を変更しない。正規化後c₀は丸め誤差を除き原点。
3. `c_k = (1/N) Σ z_n exp(−i 2πkn/N)`、N=128。負符号、1/N正規化。k=0…63はf=k、k=64…127はf=k−128。Nyquistは−64。
4. c₀は中心位置でKに含めない。非DCの127項を `round(|c_k|×10¹²)` の降順で並べる。同振幅の数値誤差を吸収するため10⁻¹²刻みで同値扱いする具体化。同値は |f|、f、DFT番号の昇順。非推移的な近似比較はせず、係数自体は丸めない。
5. `z_K(t) = c₀ + Σ c_k exp(i 2πf_k t)`、S_Kは振幅順の先頭K項、K=1…127、0≤t≤1。係数(x_k,y_k)の寄与は `(x_k cos θ−y_k sin θ, x_k sin θ+y_k cos θ)`、θ=2πf_k t。半径は|c_k|、出発角度はarg(c_k)。正周波数は反時計回り、負は時計回り。
6. 円の中心は直前の腕の終点。加算順の図であり、物理的に円が転がる仕組みではない。描画変換だけで `screenY=size/2−y×scale` と反転。参考線・腕・先端・軌跡は同じ変換。
7. 視野半径は `1.12×max(1.05, |c₀|+Σ全127項の半径)`。プリセットごとに固定して連鎖全体を収め、Kでは再正規化・ズームしない。
8. 微小項もKと計算に含む。画面半径0.25px未満の円弧だけ描画省略。表示値は約5有効桁、絶対値0.000005未満は0。半径10⁻¹²未満の位相は「微小項のため不定に近い」。負のゼロは表示しない。

RMSEは元128標本位置 `t=n/128` で計算したモデル座標の二乗平均平方根誤差。連続輪郭全体の最大誤差ではない。振幅順の追加で標本MSEは数値許容誤差内で非増加になるが、各点の誤差の単調改善や周波数順の追加は意味しない。

## 自作プリセットの元座標

外部素材や固定画像を使わない。全て `src/fourier.ts` の `outline()` に定義。

- 円：j=0…511の `(cos(2πj/512), sin(2πj/512))` を順につなぐ512頂点の折れ線。128標本は解析的な円と一致する精度。
- 星の外周：j=0…9、角度 `π/2+2πj/10`、偶数jの半径1、奇数jは0.42。10頂点を順につなぐ単純外周であり、頂点を飛ばす交差星ではない。
- 非対称な魚：以下18頂点を順につなぎ、最後から最初へ閉じる。鼻→上側→背びれ→尾→下側→腹びれ→鼻の一筆の単純輪郭。

```text
(1.35,.08), (1.1,.38), (.65,.6), (.15,.64), (−.1,.94),
(−.3,.59), (−.75,.38), (−1.05,.13), (−1.55,.63), (−1.4,−.06),
(−1.57,−.55), (−1.02,−.22), (−.7,−.48), (−.3,−.55),
(.03,−.85), (.18,−.53), (.63,−.4), (1.05,−.18)
```

K=16は魚の背びれ・尾・腹びれと輪郭の丸まりを両方観察できる。実画像で確認して初期値を採用。教材のK=4/16/64は同じ魚・同じ尺度。

## 時間・操作契約

|操作|位相と軌跡|再生|
|---|---|---|
|初期|t=0、先端1点、参考線・円・腕ON|停止|
|再生／一時停止|現在位置から進行／保持|1周で停止、完成後は描き直して再生|
|1ステップ|格子を1進める、1/512周|再生中でも停止して1進める|
|描き直す|設定と選択を保ちt=0|停止|
|完成形を見る|現在Kの全513点、t=1|停止|
|プリセット／K|曲線再構築、t=0。選択項がK外なら解除|停止|
|速度／表示／項・記号選択|位相と軌跡を保持|保持|
|リサイズ／DPR／テーマ|同じ点列と位相で再描画|保持|
|非表示／reduced-motion有効化|位相と軌跡保持、予約無効化|停止、復帰で自動再開しない|
|作品切替／破棄|予約・イベント・observer・Canvas解放|停止|

共通モデルの `t=j/512, j=0…512` から513点を前計算する。逐次軌跡はprefix、完成形は全点、先端はstep番目。連鎖も同じ係数・位相を使う。閉じる部分を含め最大513点、周回追記なし。

速度1倍は1周4秒、0.25/0.5/1/2/4倍。rAF経過時間は最大50msのみ採用し最大26点相当の予算、端数は繰り越す。整数境界の1e−10未満の丸め誤差を吸収する。60/120Hzの等時間で同じ格子位置。遅延を取り戻さないため低速環境では壁時計より遅れる。飛んだ位相を直線で結ばず間の格子点も描く。

停止・リセット・教材切替・破棄で世代を更新。予約時世代とdisposedをコールバック内でも検査し、キャンセル後の旧処理を拒否。停止中に常駐rAFはない。

## 4段階教材と復元

①半径0.68、f=+1、位相0の1本、②半径0.68/.24/.12、f=+1/−2/+3、位相0/.6/0の3本、③魚のDFTと係数、④固定尺度のK比較。①②も128標本DFTから通常モデルと同じ再構成・連鎖・描画を通す。①②のKとプリセットは固定。全段階へ往復でき、切替時は先頭で停止して軌跡を分離。

開始前のプリセット、K、整数位相（軌跡prefixを特定）、速度、表示、項と記号、再生状態を複製。終了／Escapeで全て復元し入口へフォーカスを戻す。通常は元が再生中なら再開するが、reduced-motion有効時、教材中に非表示またはreduced-motion有効化があれば停止を優先する。動きを減らす設定でも明示再生とステップは可能。

## 描画とアクセシビリティ

`src/fourier.ts` はDOM・Canvas非依存の数学と時間予算、`fourier-render.ts` はSceneから描画、`fourier-view.ts` はHTML・状態・教材・ライフサイクル、`fourier.css` は作品限定スタイル。登録だけ `main.ts` に追加。

同時に1作品・1Canvas。毎フレーム最大127円と腕、512区間を更新するのでCanvas 2Dを選んだ。SVGでも可能だが既存作品の描画方針に合わせ、操作・ラベル・説明はHTMLに残す。小さい円を直接狙う必要はなく、native selectで項選択。タップ・クリック・キーボードで全操作が可能。選択は太線・四角・#番号でも表し、色だけに依存しない。Canvasには画像の名前と観察欄への説明関係、観察値はaria-live=off。式は第9作と同じ固定Unicode・文章説明・記号ボタン。

暗色は青の細線・金の軌跡・白い先端、明色は青・濃い金・濃紺。参考線は破線。800px以下は図→操作→式の縦並び。ボタン44px以上、フォーカス枠、pan-yでページスクロールを維持。ドラッグ専用操作・センサー・権限は不要。URL状態や永続化は既存同様に導入しない。

DPR上限2。CSSサイズ変更とDPR変更だけバッファ再作成しモデル状態は保持。ResizeObserverと解像度media queryは終了時に解除。Canvas非対応は説明と数式・値を残し再生無効。
