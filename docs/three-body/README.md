# 017 三体の舞踏 / Three-Body Dance

作品選択の「017」。初期表示は8の字、時刻0、停止。3天体すべてが互いを引き合う2次元の無次元模型です。実際の太陽系の縮尺・天体暦ではありません。

## モデルと計算

`drᵢ/dt=vᵢ`, `aᵢ=G Σⱼ≠ᵢ mⱼ(rⱼ−rᵢ)/(|rⱼ−rᵢ|²+ε²)^(3/2)`。

基本G=1。位置・質量・速度は無次元。ε=0は厳密なニュートン**方程式**ですが、軌道計算は倍精度・有限刻みの近似です。ε>0はPlummer型ソフトニングを施した別の近似モデルです。特に「混沌の接近」はε=0.15で、特異な非軟化のPythagorean問題と同じ軌道とは説明しません。全ポテンシャルは`U=−Σᵢ<ⱼGmᵢmⱼ/√(rᵢⱼ²+ε²)`。固定中心、反発、合体、消滅は導入していません。

Velocity Verlet：`r'=r+vΔt+a(r)Δt²/2`、`v'=v+[a(r)+a(r')]Δt/2`。適用したΔtは実験の途中で変更しません。1ステップは常にこの更新1回。変更した刻みは「設定を適用」で時刻0から実験し直します。再生速度は実施するステップ数を変えます。40ms間隔の壁時計要求を蓄積し、1回最大2000ステップ。非表示・遅延時の過大な壁時計追いつきは捨て、モデルのステップ自体は飛ばしません。低いΔt・高速設定では指定した物理時間/秒に届かない場合があります。

最小距離<0.1は近接警告。ε=0では距離0.001、ε>0では0.0001を停止距離とします。さらに各ペアの`Δt√(G(mᵢ+mⱼ)/(r²+ε²)^(3/2))>0.12`で時間解像度不足として停止します。ステップ内の相対位置を結ぶ線分の最接近も検査します。これは衝突の厳密な時刻決定や一般の精度保証ではありません。拒否したステップは反映せず、直前の確定状態と理由を表示。自動的な刻み変更はしません。

操作上の範囲は質量10⁻⁶〜1000、初期座標±10000、初速度±100、G=0.01〜10、Δt=10⁻⁵〜0.01、ε=0〜0.5。任意の範囲内初期値の長時間精度を保証するものではありません。比較δの絶対値は10⁻¹⁰〜0.01です。

## 保存量と誤差

`K=Σmᵢ|vᵢ|²/2`、`E=K+U`、`P=Σmᵢvᵢ`、`L=Σmᵢ(xᵢvyᵢ−yᵢvxᵢ)`、`R=Σmᵢrᵢ/M`、`V=P/M`。連続モデルではE・P・Lが保存され、Rは一定速度で動きます。現在値・初期値・差分を別列で表示します。

ゼロ付近の初期保存量で割らないため、`S_E=max(K₀+|U₀|,10⁻¹²)`、`S_P=max(Σmᵢ|vᵢ₀|,√(MS_E),10⁻¹²)`、`S_R=max(maxᵢ|rᵢ₀−R₀|,10⁻⁶)`を採用。誤差は`ΔE/S_E`、`|ΔP|/S_P`、`ΔL/(S_PS_R)`、重心残差`|R−R₀−V₀t|`です。「全エネルギーに対する通常の相対誤差」とは異なります。

正三角形は特殊な相対平衡解です。等質量のものは摂動に不安定であり、浮動小数点の丸め誤差も増幅します。予備計算ではt≈116で接近による安全停止に至りました。長時間も正三角形を強制するような位置補正は行いません。

逃走例では二重星重心に対する相対比エネルギー`e=|v₃−V₁₂|²/2−G(m₁+m₂+m₃)/|r₃−R₁₂|`と外向き速度を用います。初期e<0から、t=30で距離約36.38、e≈0.844、外向き速度≈1.342。遠方での単極近似による離脱傾向であり、無限未来の脱出証明ではありません。

## 操作と比較

数値入力・プリセット選択は候補だけを変更。「設定を適用」で検証した候補を新実験にします。不正値は現在の実験を保持します。リセットは適用済み初期条件を再現し、候補は保持。停止時の編集モードではCanvasで候補位置をドラッグでき、同じ値を数値入力でも編集できます。

再生・停止・1ステップ、拡大縮小・平行移動、全体表示、固定座標、重心追従、各レイヤーの個別表示、履歴長・不透明度、鑑賞モードを備えます。全体表示は明示操作時だけ。背景発光は装飾。軌道は確定計算点を直線で結び、平滑化しません。天体は円1・四角2・三角3で識別。Canvasにフォーカスして左右キーで選択、ドロップダウンでも選べます。通常のタッチはページスクロールを優先し、編集モードのみドラッグを捕捉します。マウスホイールやピンチの専用カメラ機能はなく、ボタンとブラウザ標準拡大を使います。

比較は適用済み初期値からA/Bを時刻0へ作り、Bの1天体のx/y/vx/vyの1成分だけにδを加えます。A/Bとも同じ積分法・Δt、ステップを同時確定。一方が安全停止なら両方ともそのステップを反映しません。通常実験は別途保存され、比較終了で復元します。広い画面では左右、600px以下では実線A・破線Bの重ね合わせ。カメラは共通の座標原点・尺度を使います。

`D(t)=√(Σᵢ|rᵢᴮ−rᵢᴬ|²/3)`、`D_c(t)=√(Σᵢ|(rᵢᴮ−Rᴮ)−(rᵢᴬ−Rᴬ)|²/3)`。位置摂動ではD(0)=|δ|/√3、速度摂動ではD(0)=0です。描画の整数ピクセルで比較しません。個別位置差、現在D、20ステップごとの時系列、直近20点の表、両系の保存誤差を表示します。初期値敏感性と数値誤差増幅は区別する必要があり、有限時間の差だけでカオス・リアプノフ指数を断定しません。関連する刻み幅再実験は[sensitivity-results.json](sensitivity-results.json)参照。

## 教材・インスペクター

記号r/v/a/m/G/t/Δt/Σ/E/L/δを選ぶと、名前・読み方・意味・Aの同じ時刻の数値・図の対応するベクトル／観察パネルを強調。Σは選んだ天体に対する2項を一つずつ数値表示します。緑の速度矢印は値×0.25、赤の加速度矢印は値×0.15の座標長で、別の尺度です。

4段階は距離倍率実験→正三角形のステップ観察→同じt=1での刻み幅比較→微小差比較。開始前の実験・比較・履歴・候補入力・選択・カメラ・表示・再生意図を深いコピーで保存し、終了/Escapeで復元。途中に非表示やreduced-motionの安全停止が起きたら自動再開しません。reduced-motion中は自動再生を止め、明示的な1ステップを使います。

## 構成と視覚設計

計算`three-body.ts`、状態`three-body-state.ts`、Canvas/座標変換`three-body-render.ts`、DOM`three-body-view.ts`、教材定義`three-body-inspector.ts`。API・認証・外部データ取得は使いません。作品選択→候補検証→同期計算→確定値・描画の流れです。新しいランタイム依存はありません。

分析課題は平面軌道の時間変化と2実験の比較。主表示は3系列の実軌道で、連続再描画のためCanvas 2Dを選択。描画時は保存した各履歴から最大1000点/天体を等間隔で選び、最初と最後を保持します。存在する計算点だけを使い、座標の補間生成はしません。表示ポリラインの間には省略した計算点があるため、細部は表示解像度に制限されます。保存履歴6000点と物理計算は変えません。D(t)は軸ラベル中心の小グラフなのでSVG、読み上げ・数値入力・表はHTML。SVGのみでも構成可能ですが、軌道点の大量DOMを避けます。両方の可視化・アクセシビリティはこの実装内で整合確認しています。独立レビューは未実施です。

| 視覚層 | データ・符号化 | 代替情報・QA |
|---|---|---|
| 軌道 | 3体×最大6000確定点を保持、表示は最大1000点/体、x/y固定座標、青円1・橙四角2・紫三角3。選択白枠、速度緑、加速度赤 | 数値観察・各加速度寄与。実サンプル・端点・履歴不変、モデル→画素位置のGUI検査、カメラ逆変換の単体試験 |
| A/B比較 | 同一座標、同色同番号、B破線と輪郭。狭幅は重ね合わせ | 各位置差、D/D_c、時刻、双方保存誤差。同期・原状態復元試験 |
| D(t) | 実物理時間の線形横軸、0起点・窓内最大値の線形縦軸、平滑化なし | 現在値・軸範囲の文章・直近20点の表。数値とパスの単体試験 |

最大2枚のCanvas、DPRは2で上限、CSSサイズからバッファーを再計算。1枚のバッファー見積りは`width×height×DPR²×4`byte。軌跡6000、グラフ1200のリングバッファー。教材・通常実験の保存コピーも有限。非表示時停止、離脱時にタイマー・rAF・イベント・ResizeObserverを破棄。未完了の非同期物理計算は存在せず、描画予約は1件に集約します。

スマートフォンでは作品と主操作を先に、設定は下へ。Canvasより小さい数値入力だけに依存せず、44px以上のボタンを用意。ページ内・URL・localStorageには実験を永続化しません。ページ再読み込みは初期状態へ戻ります。ソースモジュールから状態を復元する共有URL機能は対象外です。
