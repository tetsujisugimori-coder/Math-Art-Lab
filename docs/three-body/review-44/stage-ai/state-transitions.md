# Independent state lanes

Stop: NOT_REQUESTED -> REQUESTED -> SENT -> ACKED; SEND_FAILED and REJECTED are failures. Exit: NOT_OBTAINED -> CONFIRMED or UNCONFIRMED. Resources: NOT_OBTAINED -> RELEASED only after confirmed exit. Persistence: NOT_STARTED -> WRITING -> COMMITTED, or FAILED/INCOMPLETE. Send/ack success is not exit, exit is not resource release, resource release is not saved evidence. Mock exit.confirmed is synthetic assertion, never native proof.

The monitor checks enrolled handles, chooses stop, records send outcome, checks actual process/job exit independently, then releases resources. Missing native confirmation is UNCONFIRMED. Future adapter must supply handle-based exit proof, not trust worker self-reported exit. Stop refusal/send failure/response loss each preserve uncertainty. No unrelated process is targeted.

Original timeout5000ms, parent safety30000ms and overall90000ms remain AH ceilings. M must act independently at parent deadline; no extra grace is approved. Stop/confirmation/storage must fit remaining ceiling. At total ceiling unresolved exit is UNKNOWN/UNCONFIRMED; no invented waiting extension. Implementability of this budget is NOT_TESTED and could block future approval. On first execution, observation, identity or evidence failure the remaining slot is BLOCKED; no retry/replacement/reorder.

Worker/parent no response, communication loss, monitor death/hang, process abnormal exit, stop refusal/send error, missing exit response, save failure, capacity exhaustion, receipt mismatch and buffer overflow all stop progression. M may still attempt only identity-verified containment despite storage failure; monitor inability means stopping guarantee UNKNOWN. Capacity failure maps save.failed, receipt mismatch maps INCOMPLETE, buffer overflow observation FAIL. Persistence cannot lock the stop path or introduce unbounded synchronous waits. An interrupted write is partial raw evidence with no committed receipt. Existing files are never replaced.

AH classifier retains execution FAIL independently from observation FAIL/NOT_OBTAINED and evidence incomplete. Timeout ordering requires same-domain begin/decision/end; before/between/after remain distinct. Begin + decision without end means timeout reported after begin AND completion UNKNOWN. Missing decision cannot infer timeout position; end absence cannot infer physical interruption.
