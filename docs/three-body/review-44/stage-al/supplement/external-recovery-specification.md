# AK01 external R implementation boundary

recovery-contract.json fixes station/owner/operator/recovery roles and separate source proof obligations. All actual station/VM/hypervisor/manager/ACL identities remain NOT_OBTAINED. R is outside guest OS with VM-only authenticated endpoint access. A management API provider/command family cannot be selected without the actual hypervisor; this is an explicit implementation-readiness blocker, not a claim of a working endpoint.

Enroll immutable VM UUID/imageSHA/generation/hypervisorUUID, station/session/epoch and source/budget policy before guest start. Require external ledger persistence and independent readback of that enrollment and consumed-command nonces before admitting guest creation. Runtime sample equality is not mutual authentication. Credential material belongs in a separately approved station OS protected service credential store; only keyID/fingerprint/issuer/expiry metadata appears in evidence. No secrets in argv, environment dumps, manifests or logs. Revocation immediately denies enrollment/new operations; reissue requires new reviewed key/session/epoch, not reuse of old capability. No actual credential issuance/ACL change occurs.

ACL grants status read and stop only for the enrolled disposable VM; deny host-wide controls, other VM IDs, role administration, creation and rollback privileges. Nonce uniqueness, target generation, epoch and sequence survive in immutable external ledger. A crash between reservation and send leaves UNKNOWN/BLOCKED; do not automatically replay/retry a command whose execution is uncertain. Rollback to a new generation invalidates old enrollment and uses a new evidence namespace, retaining old receipts outside the VM.

R uses its own received-heartbeat timestamp and hard ceiling, independent of M timers or guest timestamps. Actual clock provider/frequency and heartbeat schedule are NOT_BOUND; no production timing configuration is invented. AK's5/6/8/9/10-second and25/26/28/29/30-second milestone proposals remain NOT_APPROVED. Existing5000/30000/90000 and qualification8x10000/90000, retry0/replacement0/no reorder remain. Preparation/polling/stop/storage/cleanup feasibility NOT_TESTED; first failure blocks remaining slots. No hidden grace or missing-slot promotion.

Separate lanes: requested STOP, management accepted request, fresh target VM stopped, guest processes exited, resources released, external evidence persisted. Each needs its own original status/target/epoch/nonce/receipt source. VM power-off may destroy guest volatile raw and never proves individual handle close/normal exit. Guest link loss is not kernel/process death; kernel hang does not establish an operational management route. R/station/endpoint/ACL/ledger failure means guarantee NONE/UNKNOWN/BLOCK_REMAINING. A hung R cannot reliably issue its own failure event: mock R_HANG is an external-observer assertion, not an implemented self-diagnosis guarantee.

Human recovery is separately owned/manual, without finite automatic guarantee. Independent console/account/runbook/target identity and evidence boundary must be physically verified under separate approval; none is available. No human promise, successful mock STOP, API acceptance or well-typed status closes AK01. No R process, VM, management command, credentials or privilege change is implemented or run here.
