# Finite synthetic failure matrix
fault-fixtures.json fixes each input, expected reason and expected remaining state before formal execution. fault-results.json stores actual output and baseline classification; standalone negative controls are not additional Vitest counts.
Common expectations: observation FAIL, evidence INCOMPLETE, remaining BLOCKED, raw already acquired retained, known runner FAIL latched, physical NOT_TESTED, AK01 NONE, AK02 UNKNOWN and gate false. Late success is quarantined, not recovery.
M hang/crash/kill; R hang/unreachable; heartbeat/IPC disconnect; revoked/expired credential; rollback/identity/generation/epoch/replay; persistence/readback/corrupt/hash failure; Job create/assignment/creator/handle/nesting/breakaway/resume/PID faults; false-stop and cleanup all have explicit reason codes in fault-fixtures.json. Missing/corrupt event structure or capacity is rejected safely. Limits64 events/65536 UTF8 raw event bytes/16384 receipt characters; bounded prior raw retained on overflow.
Only receipt-backed separate synthetic lanes may report synthetic stopped/exit/release/persist; no physical PASS. Empty trace means not observed, not PASS execution. Malformed later inputs never erase a valid earlier FAIL. Process CPU, elapsed, timeout location and resource events stay in AL's separate domains and are not recomputed by AM.
RED must mean actually executed old source accepted a same-input counterexample to its existing contract. New AM protocol obligations have baseline NOT_APPLICABLE, not fabricated RED. Existing AL gate is independently run on the same new inputs and its denials are BASELINE_PASS. Unexecuted AM draft concerns are NOT_TESTED, never historical RED.
