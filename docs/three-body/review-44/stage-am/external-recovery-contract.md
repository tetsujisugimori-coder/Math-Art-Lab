# AK01 external recovery obligations (OPEN, actual guarantee NONE)
R location/owner/operator/recovery owner, hypervisor and VM are NOT_OBTAINED. R must be enrolled before guest creation with VM UUID, image SHA256, generation, epoch, hypervisor/station IDs, session/trial and source/plan/environment. A different process in guest is insufficient separation.
Enrollment receipt must contain canonical original bytes, record ID, raw size/SHA, authenticated ledger origin, independent reader identity and readback bytes/SHA. Durable commit plus independent readback and nonce ledger readiness precede guest admission. A local validator-generated receipt is SYNTHETIC_ONLY, never an external receipt.
R authenticates a VM-scoped management endpoint using least-privilege read/status/stop ACL. Secrets remain in a separately approved protected store; only issuer/key fingerprint/expiry/revocation metadata belongs in public evidence. Actual trust anchors, principals, endpoint and ACL UNKNOWN. Renewal/reissue creates a new session/epoch with independent review, not continuation of a revoked campaign.
Persist consumed command nonce and monotonic ledger sequence before any future command. Uncertain commit blocks new action; no automatic replay/retry. VM rollback invalidates generation/epoch and old enrollment/approvals. Time validity needs a trusted issuer verification/time source plus an explicit policy; no JS boolean confers authority.
R measures detection and action durations only within its own bound clock; provider/frequency/time origin currently UNKNOWN. Record receive heartbeat, detection, request, API accept, independently polled fresh stopped state and readback. Neither missing heartbeat nor API accept proves stop. Deadline allocations are unapproved/not measured; existing ceilings remain, no finite guarantee is claimed.
Separate lanes: STOP requested; management accepted; VM actually stopped; guest processes exited; resources released; external evidence persisted/read back. Each requires independent original evidence. VM power-off does not prove guest handle exit or orderly cleanup. Missing remains NOT_OBTAINED.
M hang/crash/kill, heartbeat/IPC loss, R hang/unreachable, endpoint/credential/ACL/ledger failure each blocks remaining slots. Safe stop cannot wait indefinitely for storage; bounded partial raw is retained, missing tail is INCOMPLETE. No automatic unsafe action is added here. Recovery cannot be guaranteed when R/management path fails: NONE. Manual escalation is a separate future runbook with exact VM identity, authorized console owner and acquisition plan, not automatic recovery.
