# 019 · 余りが描く心臓

## 弦のモデル

整数 N=24〜720、k=2〜6（初期値280、2）。i=0,…,N−1 に対し j=(ki) mod N を計算し、
角度 2πi/N−π/2 の円周点から j の円周点へ弦を描きます。
同点への写像は長さ0で描かず、逆方向から同じ弦に重なる場合は別の接続として数えます。
画面では全点を同じ半回転・拡大縮小・平行移動に掛けます。色、光彩、星は接続先を変えません。

単位円で共通回転を省くと、連続な弦は e^(it) と e^(ikt) を結びます。
E(t) = (k e^(it) + e^(ikt))/(k+1) は弦上の点で、その接ベクトル
E′(t) = ik(e^(it)+e^(ikt))/(k+1) は弦の方向 e^(ikt)−e^(it) と平行です（両端が重合するパラメータは極限で扱う）。
これが連続包絡線となり、k=2 ではカージオイド、k=3 ではネフロイドです。
画面に描くのは有限の弦だけで、包絡線の式から輪郭を直接描いていません。

## 鑑賞

再生を押して開始します。静寂（0–2秒）、糸の出現（2–6秒）、増加（6–10秒）、
完成図（10–13秒）、タイトル（13–15秒）の順。完了後は同じ完成図で操作を続けられます。
N・k の変更は再生を止めて新しい完成図を描画します。「完成図」は待ち時間を省きます。
動きの軽減設定では初めから完成図を出し、時間演出を無効にします。非表示タブの時間は進めません。
「全画面鑑賞」はブラウザの表示領域を使う鑑賞用ダイアログで、閉じるボタンまたは Escape で戻ります。
音声は追加していません。映像と操作だけで鑑賞でき、メディア・効果音への依存や自動再生を増やしません。
