      - paragraph [ref=e207]: 空き家は分母に含めません。近隣の居住者が0人なら比率は未定義ですが、満足と扱います。満足率の分母は全住民、住民0人ならデータなし。同類隣接比率は、両端が居住中の8近傍の隣接ペアを重複なく数えたうち、同色の割合。ペア0ならデータなしです。最大同色領域も8近傍の連結で数えます。
      - paragraph [ref=e208]: B・Cは全空き家を探索します。Cは未定義の比率を順位付けせず、孤立する候補を除きます。Bは孤立先も満足として許容。移動不能者は街が変わるまで再試行せず、移動が起きたら全員を再評価します。全不満足者の移動不能が確認されたときだけ停滞と表示。10,000判断で安全停止し、収束とは呼びません。
      - paragraph [ref=e209]: 個々人が全体の分離を目標としているとは限らず、異なる集団をすべて拒絶する必要もありません。局所的な満足と街全体の混在は別の問題です。結果は閾値、人口比、空き家率、規則、初期配置、更新順序に依存します。
