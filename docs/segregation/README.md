# Experiment 015 — 分断のモザイク

シェリングの分居モデルを題材に、局所的な最低条件と街全体の模様を比較する。作品メニューの「015 · 分断のモザイク」から開始。起動時は停止、30×30・赤50%・空き家15%・θ=30%・方式A・seed=15015。

## モデルと再現

格子は有限正方形、上下左右を接続しない。近傍は中心を除くMooreの8近傍。`s_i=n_same/n_occupied`（同類数÷近隣居住者数）で、空き家は分母から除外。`s_i≥θ`なら満足。近隣0人は比率未定義（表示「データなし」）、満足とする。θは個人の近隣への最低条件であり、街全体の望ましい人口構成ではない。

初期人数は `空き家=round(N²×空き家率)`、`人口=N²−空き家`、`赤=round(人口×赤割合)`、`青=人口−赤`。赤1・青2の色と不変IDを割り当て、Mulberry32の32bit seedとFisher–Yatesでセルを並べ替える。0も有効なseed。人数・色・ID・空き家数は移動で変わらない。seed以外の設定も同じ場合、同じ操作列とステップ数で再現する。

1ステップは、不満足で現在の街における移動不能がまだ確認されていない住民1人を一様無作為に選ぶ判断。結果を即時に適用する非同期・逐次更新。移動しない判断も1ステップ。満足者は移動しない。満足者の移動判断や全員の同時更新を1ステップとは呼ばない。

| 方式 | 移動先 | 打ち切り |
| --- | --- | --- |
| A 無作為 | 元から空いている全セルから一様選択。移動後の満足を保証しない | 空き家列挙1回 |
| B 条件を満たす空き家 | 移動後に満足する全候補から一様選択。孤立先も満足 | 全空き家を各1回評価 |
| C 同類比率を最大化 | 現在より厳密に高い比率のうち最大の全候補から一様選択 | 全空き家を各1回評価 |

B・Cの行き先評価では移動元を空けて数える。Cでは未定義の比率を数値へ置換せず、孤立する行き先を順位付けの対象から外す。これは本作品の明示的な仮定。B・Cは比較用のバリエーションで、原著と同一の手続きとは主張しない。

「選択住民の判断を試す」は、選択IDの不満足者に同じ移動規則を適用する手動介入。この場合だけ選択順の乱数を消費しない。その後の判断列は自動実験と異なり得る。選択IDは移動後のセルへ追跡する。行・列と矢印キーはセル選択の代替操作。

## 停止の意味

- **全住民が満足**：不満足者0人。住民0人の街もこの分類だが、満足率はデータなし。
- **有効な移動先なし**：空き家0、または街の最終変化以降に全不満足者が全空き家を調べて移動不能と確認。1人が動けないだけでは停滞と呼ばない。確認済みIDは街が変わるまで再試行せず、1件でも移動したら確認を全解除。
- **上限到達**：10,000判断。収束とは表示しない。Aは移動や変動が長く続くこともある。
- **継続可能**：上記以外。B・Cで移動先なしの住民を確認中の場合も含む。

探索は有限の全空き家列挙なので、試行し続ける内側の無限ループはない。長時間の再配置は全体の判断上限で停止。一時停止は以上のモデルの状態とは別。

## 社会実験室と指標

入力は候補で、設定の選択やスライダー操作では街を再生成しない。「入力した設定から街を生成」で明示的に確定する。「同じ街で再実験」は適用中のサイズ・人口比・空き家率・seedを保ち、候補のθ・規則だけを確定して同一初期配置と初期化後の乱数状態から始める。分岐後は規則によって乱数の消費数が異なり、各住民に同一乱数を割り当てる実験ではない。

「現在結果を比較に固定」は街・適用条件・指標・履歴のスナップショット。初期状態／固定結果と現在の街を左右比較（狭幅では上下）、表で比較できる。新しい街を生成すると固定結果を解除、同じ街の再実験・リセットでは保持する。比較はブラウザ内だけで保存し、再読み込みでは失われる。URL共有・外部保存機能は追加していない。

| 指標 | 定義・単位 |
| --- | --- |
| 満足率 | 満足人数÷全住民、%。住民0人ならデータなし |
| 不満足者 | 現在のθで最低条件を満たさない人数 |
| 同類隣接比率 | 両端が居住中の8近傍の無向ペアを1回ずつ数えた中の同色ペア割合、%。分母0ならデータなし |
| 引っ越し | 実際に位置を変えた累積回数 |
| ステップ | 移動判断の累積回数 |
| 最大同色領域 | 8近傍で連結する同色住民の最大人数 |

満足率と隣接比率は異なる。θ=0%なら混在していても全員満足できる。同類隣接比率は人口比にも影響され、異なる人口比の間で中立的な「分断指数」になるわけではない。因果推定や現実の分離度の測定ではない。

グラフは横軸が実際の判断ステップ、縦軸0〜100%。満足率は実線、同類隣接比率は破線。系列は個別に非表示可能で、現在値を併記。直近601点は判断ごとに正確に保持し、ローリング範囲の両端を表示。平滑化・単調化・欠損の補間なし。初期状態と固定結果は履歴の範囲外でも別保持。

## プリセット

全プリセットで格子サイズ・seedは入力候補を保持し、選択後に生成ボタンで確定する。初期値は30×30、seed=15015。結果保証ではなく、条件による違いを観察するための例。

| 名称 | θ | 赤:青 | 空き家 | 方式 | 観察の意図 |
| --- | --- | --- | --- | --- | --- |
| ほぼ選好なし | 0% | 50:50 | 15% | A | 混在と全員満足は両立する |
| 弱い同類選好 | 30% | 50:50 | 15% | A | 少数側でよくても同色の塊が育つ場合 |
| 中程度 | 50% | 50:50 | 15% | B | 満足する行き先に限る影響 |
| 強い | 80% | 50:50 | 15% | C | 改善しても満足とは限らない |
| 空き家が少ない | 30% | 50:50 | 2% | B | 行き先の不足 |
| 人口比が偏る | 30% | 80:20 | 15% | A | 少数側の条件と隣接指標の人口比依存 |

## 4段階教材

1. 赤と青の街：16×16、住民／空き家／境界を選択して観察。
2. 一人の引っ越し：不満足な住民をIDで選択済み。3×3図、人数、代入式、選好条件を読み、本人の判断を試す。
3. 小さな選好、大きな変化：30×30、θ=30%、同じseedで再生・初期比較。
4. 分断のモザイク：全条件を操作して比較実験。局所的な最低条件と街全体への意図を区別する1問と解説。

段階の説明と操作対象・代入式は実際の街の状態に同期する。開始前の街・乱数・履歴・固定結果・表示・未適用設定候補を保存し、閉じる／Escapeで復帰。復帰は一時停止とし、非表示／reduced-motionによる停止を優先する。

## 描画と技術設計

既存のTypeScript / Vite / Vitest / Playwrightを維持し、依存追加なし。`segregation.ts`はDOM・時刻なしの数理、`segregation-render.ts`はCanvasとSVG座標、`segregation-view.ts`は状態の所有とUI、CSSは`.mosaic`内へ限定。

分析の仕事は格子内の局所構成の観察と時系列・初期状態との比較。Canvas2Dは最大1600セル×2画面、SVGは2系列の最大601点ずつ。Canvas/SVGスキルによるローカル設計・点検を行い、新しいグラフライブラリは不要と判断。Canvasが描けない場合もHTMLの指標・行列選択・近隣図を代替とする。

赤は暖色、青は寒色、空き家は暗い中立色。赤の点／青の斜線を既定で有効化。白は選択／近隣、金は直近の元（破線）と先（実線）。色を統計の強度や住民の満足判定に転用しない。街は等面積セルのまま、2倍表示でも格子数・ヒット判定は同じ。位置はCanvas矩形を行・列へ逆変換。ブラウザの拡大とスクロールを許可し、独自のピンチ操作は持たない。

CanvasはDPR上限2、幅に合わせて正方形バッファを作る。時系列ラベル・凡例・操作・テキストはDOM/SVG。通常1枚・比較時2枚、幅600px/DPR2なら1枚約5.76MB、2倍表示では約23.04MB。描画の入力から乱数を呼ばず、表示切替・描画回数は判断列を変えない。再生は1〜30判断/秒の逐次タイマーで、処理が重い場合は壁時計上の速度が落ちる。追いつくために判断を飛ばさない。

非表示とreduced-motionの有効化で一時停止、金枠はreduced-motion時に省略。初期からreduced-motionでも明示的な再生は可能。移動補間や点滅はなく、確定した街だけを描く。作品の切替時はタイマー、ResizeObserver、rAF、イベント、保持状態を破棄する。

## 社会科学的な位置付けと限界

局所的な選好が、個人の意図とは異なる全体の結果を生む可能性を見る模型。すべての人が異集団を拒むことや、街の分離を目標にすることを前提にしない。赤と青は抽象的な二集団であり、民族等を直接表さない。

現実の居住分離には価格、所得、制度、差別、交通、歴史などの要因があり、この模型から現実の原因を断定しない。二集団、一律閾値、同じ移動能力、移動費用なし、人口固定、有限境界、更新順序は本実装の仮定。シードや条件次第で結果は変わる。

参考：Thomas C. Schelling, *Dynamic Models of Segregation*, Journal of Mathematical Sociology (1971), [DOI](https://doi.org/10.1080/0022250X.1971.9989794)。原論文本文はこの環境で403のため未取得。全手続きを原著に照合したという主張はしない。[Stanford Nifty教材](https://nifty.stanford.edu/2014/mccown-schelling-model-segregation/)は空き家を分母から除く規則と、教育用の実装例・バリエーションを確認。Niftyの全不満足者をラウンドごとに移動させる説明とは更新順序を区別した。
