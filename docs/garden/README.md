# 光の花園の確認画像

Chromium、1280×1000 / 375×1000、動きを減らす設定あり。すべて実際の計算データからThree.jsで描画したもので、生成画像は使用していない。

- [黄金角・1,200点（1280px）](golden-1280.png)：180(3−√5)度。中心から外への色と、独立した点・隙間を確認。
- [120°・1,200点（1280px）](120-1280.png)：3方向への整列。外側では点が密に重なり線状に見えるが、接続線は描いていない。
- [少数点の角度解説（375px）](lesson-375.png)：黄金角の6点。破線は直前の向き、実線は現在の向き、弧と矢印は中心まわりの回転を示す。

黄金角の近くは137.3°を実描画で比較し、違いが見やすい巻き方になったため採用した。90°の4方向もブラウザで確認した。これらの追加画像は比較時だけ撮影し、コミットする資料は上の3枚に絞った。

両ブラウザのE2Eで1280 / 390 / 375px、狭幅DPR=2、タップ、200%文字拡大、数式・角度・半径、教材からの復帰、複数回のリサイズと旧GPUコンテキスト解放を確認する。WebKitはデスクトップ上のPlaywrightであり、実機iPhone Safariの試験ではない。
