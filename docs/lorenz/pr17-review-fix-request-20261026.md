### P2: 非ゼロの微小差分δが0と誤表示される

対象: `src/lorenz-view.ts` の `fmt()`（4行）と図中注記生成（126行）。

`fmt()` は `toFixed(5)` で小数点以下5桁に丸めるため、許容最小値 `δ=1e-8` を適用し、数式中のδを選択すると、`#lorenz-annotation` が「適用値 0」と表示する。内部のRK4計算、適用値一覧、距離表示には非ゼロの値が使われるため、説明と計算が矛盾する。初期値鋭敏性が主題の教材として修正を要する。

既知のP0/P1指摘はないが、独立した実ブラウザ再実行、実機Safari、GPU負荷測定は未実施のため、未検証事項を残す。マージ・公開更新は保留する。

### 修正方針

1. 表示用の数値フォーマットで、非ゼロの微小値が0と誤表示されないようにする。通常値は読みやすい小数表記を保ち、小さい値には指数表記を使うなどの方針を明文化する。
2. 真の0と、丸めれば0になる非ゼロ値を区別する。不必要な `-0` の表示を防ぐ。
3. δの図中注記、適用値一覧、初期差分、同時刻距離が意味として整合することを確認する。
4. 同じフォーマットを利用するx・y・z、係数の表示も確認する。表示は約値であることを維持し、精度を過大に主張しない。
5. 数値積分（Float64/RK4/固定刻み）、軌道、描画バッファ、設定上限、教材の状態保存・復元には原則手を加えない。

### 必須テスト

- **δ=1e-8:** 比較を有効にして最小値を適用する。δを数式ボタンで選んだ際の注記が0にならない。初期距離が正で、δに合理的な数値誤差内で一致することを確認する。
- **δ=1e-5:** 標準差分の数値・表示が不必要に変化していないことを確認する。
- **境界値:** 許容内の非ゼロ微小値、真の0、負のゼロ、通常値の視認性、δの範囲外入力の拒否を確認する。
- **表示・操作:** δのホバー、タップ、キーボードフォーカス、375/390/1280px、dark/lightの表示と必要なスクリーンショットを確認する。
- **回帰:** 4段階教材、プリセット、停止・再生、状態復元、既存4作品への影響がないことを確認する。
