# Experiment 020 · 無限に咲く円の花 / Apollonian Bloom

作品メニューで「020」を選ぶと、先に外円と三つの内円を表示します。再生すると、同じ3円に接する別の円が隙間に増えます。019が剰余の弦から包絡線を見せるのに対し、020は各円が周囲と接したまま世代を重ねる様子を見せます。光は描画だけの処理で、中心や半径を補間しません。音声なし。

## 数式と種

単位外円（中心原点）は負の曲率 k=−1、内円は k=1/r。中心 (x,y) について (u,v)=(kx,ky) を保持します。4円はデカルトの関係 (Σk)²=2Σk² を満たします。曲率と曲率中心座標は、置換対象を除く3項の和の2倍からそれぞれの旧値を引き、最後に x=u/k、y=v/k、r=|1/k| として復元します。[曲率中心座標の根拠（Lagarias・Mallows・Wilks）](https://arxiv.org/abs/math/0101066)、[Apollonian群と置換生成](https://arxiv.org/abs/math/0010298)。

| 配置 | 幾何学的な種 |
|---|---|
| 三輪の花（既定） | 内円の半径は r=2√3−3。外円中心から1−rの距離、120°刻みなので中心間は √3(1−r)=2r。 |
| 花びらの渦 | 宝石箱の片側の半径1/2の円を反射した非対称の種。「渦」は見た目の名称。 |
| 宝石箱 | (k,u,v) = (−1,0,0), (2,−1,0), (2,1,0), (3,0,2) の整数種。 |
| 静かな曼荼羅 | 三輪の花の上側の円を一度反射。鏡映対称を残して大小の構成を変える。 |

いずれも6組の種の接触条件を検査します。幅優先・固定インデックス順で反射し、同じ位置に対する直前操作の繰り返しは逆操作なので枝から除外。曲率単独で重複扱いせず、中心距離と半径の両方を照合します。候補の有限性、正の内円曲率、外円への包含、残す3円との接触、採用済み全円との非重複を確認。想定に反する不正な交差などは例外とし、正常表示へ混ぜません。

許容差は 512×Number.EPSILON×max（対象2円の正規化座標の絶対値・半径）です。これは倍精度計算を検査するための余裕で、丸め誤差の一般的な厳密上界ではありません。理論の無限充填と画面の有限パッチを区別します。生成は最大6段・外円込み1460円・正規化半径1e−8まで。最小半径を満たさない枝、重複した枝、候補なしで停止します。既定の5段で488円。キャンバスで物理0.65px未満になる円は画素化せず、幾何データの数と分けます。

## 鑑賞と教材

- **操作**：再生／一時停止／再開、選択設定のまま最初から、完成形、初期設定へ復帰。1〜6段、0.5〜2倍、5配色、輪郭、全画面鑑賞。
- **演出時計**：0〜2秒は種、2〜5秒は初めの隙間、5〜14秒で細部を増やし、14〜15秒で題字。生成済みリストの接頭部分だけを描きます。完成形ボタンも同じ全円を描画します。
- **教材**：内接・外接の距離 → 中央に入るもう一方の解 → デカルトの式と反射 → 有限と無限。図と計算値は対応します。教材の間は鑑賞用時計を停止し、閉じると設定・経過位置を保ったまま戻ります。Escape、終了ボタン、フォーカス復帰に対応。
- **描画**：Canvas 2D、表示面のDPR上限2／長辺1920。配置・段数別に有限モデルを記憶し、通常再生中は追加の円だけを描画。リサイズは背面から作り直し、完成の論理状態と描画済み状態を分けます。非表示タブで時計を止め、復帰から再開します。動き軽減時は完成静止図を優先。

## 確認方法と証拠

- `npm test`：対称種の厳密な第一反射、整数種の有理位置と全対の非重複、有限性、生成上限、拒否、再現性、時間区分。既存単体を含みます。
- `npm run typecheck && npm run build`：型検査・配信用ビルド。
- `npm run test:e2e -- apollonian-bloom`／`npm run test:e2e:production -- apollonian-bloom`：既存のChromium/WebKit構成を使用。制御時計の全円・全描画・題字撮影と、制御なしの通常速度完走は別試験。375／390／1280px、教材・Escape・フォーカス、再描画、作品切替も確認。可視性の自動試験はブラウザ内で通知を模擬し、OSバックグラウンドの実測ではありません。
- 参照画像：GitHub PagesのPR検証時に 390px の初期・中間・完成を添付します。正式結果・固定SHA・ログ／画像のリンクはPR本文に記録します。実機Safari・実機タッチ・長時間の連続利用は対象外です。
- ローカルでは厳密な数値検査と既存単体を確認。ブラウザの実測・描画性能と独立レビューはPRで別々に管理します。
