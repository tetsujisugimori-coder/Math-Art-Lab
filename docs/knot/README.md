# 光の結び目：確認画像

Playwrightで実際のThree.js描画を撮影。1280pxの暗色で3プリセット、375px・DPR2のライトテーマで断面ガイドと補助トーラスを確認した。動きを減らす設定で静止させ、モバイルのガイドは位置スライダー0.173（t≈1.086 rad）。最終撮影はWindows WebKit。画像は計算結果の確認用で、作品の背景や描画素材ではない。

- [五葉 T(2,5)](cinquefoil-1280.png)
- [375px・ライトテーマ・断面ガイド](guide-375-light.png)

`$env:KNOT_CAPTURE='1'; npm.cmd run test:e2e -- e2e/knot.spec.ts` で再生成する。通常のCIは画像を書き出さず、失敗画像のみPlaywright既定の出力へ保存する。画像のバイト一致をブラウザ間の合否基準にはしていない。テストは3プリセットの画像が異なること、全6ガイドが通常表示へ補助表示を加えること、数式・座標・操作・有限値・資源解放を別に確認する。

実機iPhone Safariは未検証。線の中心は厳密式で、表示は有限標本の管。トーラス表面からの微小な表示用の厚みは数学の曲線と区別する。
