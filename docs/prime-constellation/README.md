# Experiment 021 — 素数の星図 / Constellation of Primes

[制作依頼 #61](https://github.com/tetsujisugimori-coder/Math-Art-Lab/issues/61)。既存の Canvas 2D と作品メニューを使い、WebGLなしで鑑賞できる。20件目の登録で、欠番017は変更しない。

## 数学と表示

- 1 は素数でも合成数でもない。0 は配置しない。2 は唯一の偶数の素数。エラトステネスの篩では、素数 p ごとに p² から p の倍数を合成数として印し、p² ≤ N の間だけ続ける。
- 双子素数は (p,p+2) の両方が表示上限までに入る組。例えば 5 は (3,5) と (5,7) の両方に属する。双子素数レイヤーは選ばれた素数の色を変え、素数一般のレイヤーを消して単独表示できる。
- ウラム：1 は (0,0)、2 は (1,0)。右・上・左・下の反時計回り、区間長は 1,1,2,2,3,3,…。数学の y は上向き、Canvasへ写すときだけ反転する。斜めの筋は有限範囲における観察であり、全ての値が素数になるという証明ではない。
- 極座標：r=√n、θ=n ラジアン、(x,y)=(r cos θ,r sin θ)。格子：列数 C=⌈√N⌉を選んだ範囲内で固定し、x=(n−1) mod C、y=−⌊(n−1)/C⌋。
- 色、光量の重なり、カメラ、表示時間は演出。星の中心は整数 n に対応する座標から動かさない。独立した背景星は描かない。合成数は灰色、座標・整数ラベルは切替。ラベルは拡大時（17 CSS px/単位以上）、読める密度に間引く。最密領域では任意の整数を数値入力で照会できる。双子素数が無限に存在するかは未解決。
- 素数の割合は π(N)/N（正整数 1…N を母数とした表示値）。スケール・速度・配置を変えても同じ N の判定は不変。0/1や上限、既知件数、全10万整数の試し割り、三配置の座標、独立な螺旋歩行、双子対の切断境界は単体試験で照合する。

## 鑑賞と教材

上限は100・1,000・10,000（既定）・25,000。モデルの検証上限は100,000。再生開始後の作品時刻は 0–3 秒「宇宙の誕生」、3–7 秒「星々の出現」、7–12 秒「隠された秩序」、12–15 秒「星図の完成」。通常は再生待機、動き軽減は完成図を即表示。停止、再開、再描画、完成図、0.5–2倍速、全画面相当の鑑賞ダイアログを備える。実際の全画面APIを要求しない。

図をクリック／タップして見えている点を調べる。ポインターで移動、2指で拡大縮小、または拡大・縮小ボタンとキャンバス上の矢印キー・+/−・0を使う。整数入力で選んだ点の分類と数学座標が読める。教材は「定義／篩／ウラム／配置と分布」の順。篩の4操作で99→50→34→28→25（1除外済み）。教材には独立した図を使い、終了すると元の鑑賞状態（再生中なら再開）に戻る。タブ非表示分は再生時間に積まない。

## 再現・計測

- `npm test`、`npm run typecheck`、`npm run build`
- `npm run test:e2e -- e2e/prime-constellation.spec.ts`、`npm run test:e2e:production -- e2e-production/prime-constellation.spec.ts`
- 作品時刻を制御する試験（途中画面・完成題字・画素比較）と時計に介入しない通常1倍速の完走試験は別。
- 篩・座標計算は設定変更時だけ。現在の上限につき配置ごとに最大3組の型付き配列をキャッシュ。通常再生の塗り直しは約30fpsまで。DPRは2で制限し、画面外は描かない。描画命令の費用は表示した範囲・レイヤーに依存する。縮小時に複数の点が同じ画素に入ることと、数理座標の一致は別。
- ヘッドレスブラウザの狭い画面での確認は実機性能や実機Safariの検証ではない。正式CI、独立レビュー、保存済み証拠の状態は対象HEADごとの記録で区別する。
