# Cobweb Model 検証記録

2026-11-05 / Windows / Node.js 24.20.0 / Chromium・WebKit / Playwright 1.58系。

## 途中で検出した失敗

1. PowerShellの実行ポリシーで `npm.ps1` を起動できなかった。ポリシーを変更せず `npm.cmd` を使用した。
2. 制限環境ではesbuildが親ディレクトリを参照できず、Vitestの設定読込に失敗した。許可された実行環境で同じ標準コマンドを実行し、289単体テストと型検査・ビルドに成功した。テスト・製品コードの修正で回避したものではない。
3. 開発E2Eの初回は既存4173番サーバーを再利用し、別作業フォルダの第12作までしかない旧版を参照した。Chromiumの最初の3ケースが選択肢待ちでタイムアウトし、中断。以後は4273番を専有して当該作業フォルダを起動。ほかの作業のサーバーは停止していない。開発／本番のポートを環境変数で指定できるようにした。明示ポート指定時は既存サーバーを再利用しない。
4. 最初の正しい対象への追加開発E2Eは **13成功・5失敗**。Chromium 9/9成功。WebKitは教材のEscape、ResizeObserver通知ループ、320px・200%文字時の横溢れを検出。マウス操作したWebKitのボタンはフォーカスをroot内へ移さない場合があるため、Escapeをライフサイクルで解除するdocumentイベントへ変更。ResizeObserver内の描画を次フレームへ移し、数式を横スクロール領域へ収めた。エラーを無視するフィルターや期待値の緩和は追加していない。
5. 修正後の追加開発18/18成功時点の固定HEAD `4002566` を独立レビューし、WebKitダークのネイティブselectのコントラスト不良（P2）を検出。[初回指摘と修正](review/README.md)を保存。ネイティブ描画をテーマに従う描画へ変更し、スクリーンショットの背景画素と文字のコントラスト比を測る判定を追加した。
