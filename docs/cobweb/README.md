# 需要と供給の蜘蛛の巣 / Cobweb Model

Issue [#37](https://github.com/tetsujisugimori-coder/Math-Art-Lab/issues/37)。依頼文の「第12作」は既存の振動の砂絵と重なるため、既存第13作の次の **Experiment 014** として追加する。

## 数理モデルと図の読み方

単一商品、離散時間、線形需要・供給、前期価格を次期の予想価格とする生産者を仮定する。価格・数量は仮想単位で、実測市場を推定したものではない。

```text
需要：Q_d(P) = a − bP
供給：Q_s(P) = c + dP
次期の生産：Q_(t+1) = c + d P_t
次期の市場清算：P_(t+1) = (a − Q_(t+1)) / b
均衡：P* = (a − c) / (b + d), Q* = a − bP*
価格偏差：e_(t+1) = −(d/b)e_t, e_t = P_t − P*
```

横軸Q、縦軸P。需要曲線上の `(Q_t,P_t)` から、旧価格を保って供給曲線上の `(Q_(t+1),P_t)` へ水平移動し、数量を保って需要曲線上の `(Q_(t+1),P_(t+1))` へ垂直移動する。1ステップはこの2工程を含む1期である。光点の補間は順番を示す演出であり、その間に連続的な市場価格が実現するという主張ではない。白い輪は最後に確定した市場点を示す。

`d/b < 1` は交互に収束、`= 1` は通常2周期、`> 1` は交互に発散する。厳密に均衡から始めれば全条件で固定点になる（実装は浮動小数点の有限精度）。これは **数量の価格反応係数** の比である。Pを縦軸に描いた逆関数の傾きは需要 `−1/b`、供給 `1/d` であり、見かけの傾きと係数を取り違えない。画面は小数3桁に丸めた約値、計算・分類は丸め前の値を使用する。境界のごく近くは、表示上同じ比率でも分類が異なることがある。

## プリセットと設定

|プリセット|a|b|c|d|P₀|P*|d/b|意味|
|---|---:|---:|---:|---:|---:|---:|---:|---|
|安定市場 · 静まる糸|120|1|0|0.65|40|約72.727|0.65|価格偏差が毎期0.65倍になり、反対側へ移る|
|境界市場 · 往復する糸|120|1|0|1|40|60|1|40→80→40の2周期|
|不安定市場 · ほどける糸|120|1|0|1.2|50|約54.545|1.2|価格偏差が拡大し、非負の観察領域を出る手前で停止|

最初の3期は次の価格になる。各行はそれぞれの均衡の周りを交互に動く。

|市場|P₀|P₁|P₂|P₃|
|---|---:|---:|---:|---:|
|安定|40|94|58.9|81.715|
|境界|40|80|40|80|
|不安定|50|60|48|62.4|

初期数量は `Q₀ = a − bP₀`。`a=120,c=0` を固定し、`b∈[0.5,2]`、`d∈[0.25,2]`、`P₀∈[0,a/b]` を数値入力で調整できる。空欄・非有限値・範囲外は未適用として、最後の有効な市場・履歴を保持する。適用・プリセット・初期状態へのリセットはt=0で停止し、履歴を破棄する。履歴量・速度・表示モードの変更は数理状態を変えない。

非負の図示領域は `Q∈[0,120], P∈[0,a/b]`。次期価格・数量が負、表示領域外、または非有限になる前に停止し、**計算された次期値と最後の有効期を明示する**。価格を0に切り詰めたり、表示範囲を自動拡張して発散を隠したりしない。観察は240期まで。履歴は最大80期を保持し、表示量4〜80期を選べる。240期制限はモデルの理論的制限ではなく、観察・保守上の制限である。

## 作品・教材・操作

需要は青緑の実線、供給は金の破線、均衡は菱形E、更新は桃色の糸。色だけに依存せず線種・文字・形で識別する。鑑賞表示では新しい糸ほど濃くし、発光・残像・均衡の核を使う。教材表示では発光を減らし、軸・格子・現在値・水平／垂直の工程を読む。D／S／E／糸の数式ボタンはTab・タップで図と式を連動強調する。式は既存の安全なMathMLレンダラーを使い、狭い画面や文字拡大時はキーボード操作可能な式の横スクロール枠へ収める。

4段階教材は①現象を見る、②図で理解する、③数式で理解する、④経済学として考える。教材内でも操作して比較できる。閉じる／Escapeで開始前の市場・履歴・途中工程・表示・速度・強調・入力候補・エラーを復元する。タブ非表示／reduced-motion有効化で停止した場合は、保存した再生状態より安全停止を優先する。初期表示は停止。1期2秒、速度0.25〜2倍。停止は途中の工程を保持し、1ステップは次期を確定する。

農産物の作付けと収穫は、生産の遅れを考える例として扱う。在庫、より複雑な期待・学習、情報差、政策、複数主体の違い、心理、天候・輸入などは省略する。**数式上で起きること ≠ 現実で必ず起きること。** 画面と教材の両方に限界を説明する。

参考：Thomas J. Sargent / John Stachurski, [QuantEcon: The Cobweb Model](https://intro.quantecon.org/cobweb.html)（2026-11-05参照）。生産の遅れ・前期価格による期待・市場清算の教材を参照し、本作品では供給も線形とする。本文・図・実装は独自に作成した。

## 技術設計・保守

既存のmount/dispose方式へ1作品だけ追加する。純粋な数理モデル、SVGレンダラー、UI、CSSを分離。単一SVGと最大80本の履歴で表現できるため、新しい描画ライブラリ・WebGL・画像アセットを追加しない。動く光点と更新中の2本のパスだけをrAFで更新し、静止中はアニメーションrAFを止める。リサイズ通知は次のrAFへ描画を送る。dispose時にイベント・アニメーション・リサイズ観測を解除する。

スマホでは図→数値→操作→詳細の順に縦積みする。狭幅は格子の目盛りを5分割から3分割へ減らし、SVGを実幅で再計算して文字を縮小しない。操作領域は44px以上。ドラッグ必須操作はなく、スクロールを妨げない。URL保存・外部API・永続化は既存作品に合わせて導入しない。ライト／ダークはOSのテーマに従う。

音、粒子背景、非線形供給、並列比較は省略した。軽量なSVGの発光・残像、3プリセットの同一図での比較に絞り、モデルとの対応と保守性を優先した。

## 検証と資料

数理テストでは既知の `40→94, Q=26`、次期需要と旧価格供給の一致、価格偏差倍率、均衡固定点、正確な2周期、収束、発散、非負領域からの逸脱、入力境界、240期上限を確認する。E2Eではモデルの関数を期待値として呼ばず、式から独立に計算したSVGの3頂点まで確認する。開発と本番の `/Math-Art-Lab/` 配下で同じケースを実行する。

実行結果・失敗履歴・画像は [verification.md](verification.md) に記録する。必要なときは他作業のViteを再利用しない専用ポートを指定できる（標準ポートとCIの実行方法は従来どおり）。
