## 幾何

[de Bruijn, *Updown generation of Penrose patterns* (1990), §2・図1–2・5](https://doi.org/10.1016/0019-3577%2890%2990005-8) の向き付き Robinson 半タイルによる P3 の細分化を使います。頂点 A が頂角、B/C の順序が鏡映の違いを表します。φ=(1+√5)/2 として辺 UV 上の分点を U+(V−U)/φ と定めます。

| 親 | 分点 | 子（順序付き頂点） |
|---|---|---|
| 薄い半タイル | P は AB 上 | 薄 (C,P,B)、厚 (P,C,A) |
| 厚い半タイル | Q は BA 上、R は BC 上 | 厚 (R,C,A)、厚 (Q,R,B)、薄 (R,Q,A) |

子の菱形辺長は親の 1/φ。薄い半タイルの頂角36°、厚い半タイルの頂角108°で、再構成後の菱形の鋭角はそれぞれ36°、72°です。AB に単矢印、AC に二重矢印を付け、単矢印の向きは薄 A→B、厚 B→A とします。BC は菱形の指定対角線で、同種・同じ向きの異なる側の半タイルだけを組にします。共通辺で使われる矢印の向きと種類を検査します。許容丸めは辺の同定用で、描画に使う座標には適用しません。

正十角形を交互に鏡映した薄い半タイル10個に分け、1回置換した段階を初期状態とします。初期菱形は厚5・薄5。72°回すと重なる配置です。切り出した十角形の外周でのみ残り得る半タイルは中立色で表示し、菱形数に含めません。段階6の上限は厚1855・薄1155の計3010枚と、外周半タイル80枚です。平面全体の P3 は接合規則を課すと平行移動周期を持ちません。この固定サイズの有限パッチだけで、無限平面の非周期性が証明されるわけではありません。

## 描画・再現

幾何は段階別にキャッシュします。数学ポリゴンと背景の星粒は別レイヤーです。アニメーションは有効な2段階の静止画を短時間合成する方式で、頂点を補間した形を数学的な状態とはみなしません。待機時の連続描画はありません。拡大は中心基準で、枠外の切り取りは表示上のものです。

```sh
npm ci
npm test
npm run typecheck
npm run build
npx playwright install chromium webkit
npm run test:e2e -- e2e/penrose.spec.ts
npm run test:e2e:production -- e2e-production/penrose.spec.ts
```

モデル試験は置換・両菱形の角・辺長・段階ごとの五回回転対称性と決定性、共有辺の出入り、外周、面積、凸多角形の分離軸による内部重複を検査します。数値実装を対象とする許容誤差つき検査です。Playwright は既存2プロジェクトで375px・390px、操作・描画・遷移・動きの軽減設定と Pages 用ビルドの描画を確認します。実行状況は Draft PR を参照してください。実機 Safari、物理タッチ、支援技術での試験とは区別します。
