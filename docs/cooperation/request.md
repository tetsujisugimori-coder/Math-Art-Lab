# Math-Art-Lab 第16作「協力の格子」実装依頼

【目的】
GitHubリポジトリ tetsujisugimori-coder/Math-Art-Lab に、
第16作「協力の格子」を追加してください。
テーマは進化ゲーム理論・空間的囚人のジレンマです。

赤は裏切り（D）、青は協力（C）を表し、住民が隣人との
ゲームによる利得をもとに戦略を更新する様子をCanvasで描画します。
個人の損得と社会全体の協力率が必ずしも一致しないことを、
ユーザー自身が条件を変えて実験できる作品にしてください。

【数学モデル】
各セルに協力Cまたは裏切りDの住民を配置する。
空間的な2人ゲームを近隣住民と繰り返し、得点から戦略を更新する。

利得行列：
             相手C    相手D
自分C           R        S
自分D           T        P

標準の厳密な囚人のジレンマはT>R>P>S。
初期値はT=5,R=3,P=1,S=0を候補とする。
古典的条件2R>T+Sも説明できるようにする。
条件を満たさない入力はモデルを偽装せず、ゲーム分類を変更するか
適切なメッセージを出す。弱い囚人のジレンマなども区別する。

全住民の局所得点を計算し、戦略更新に反映する。
同期更新を基本とし、旧状態の得点・戦略を基準に全員の次状態を
決めてから一括反映する。更新途中の新状態を混ぜない。

移動や戦略変更のモデルとして、少なくとも以下を実装する。
A. 最良戦略模倣：自分と近隣の高得点者の戦略を模倣
B. Fermi更新：得点差に応じた確率的模倣
C. 必要なら追加規則を実装。ただしモデル上の意味を明記

同点処理、候補選択、近傍、境界処理、得点の合計・平均の扱いを
明文化する。Fermi更新は温度パラメータの意味、確率式、
数値安定性を検証する。突然変異は模倣と別の処理として記録する。
乱数はseedを固定可能にして、同条件なら再現できるようにする。

【操作画面】
・格子サイズ
・初期協力者割合
・T,R,P,Sの利得
・近傍：上下左右4近傍／斜めを含む8近傍
・境界：固定端／周期境界
・戦略更新規則
・Fermi温度
・突然変異率
・乱数seed
・シミュレーション速度
・開始／停止／1世代進行／初期化
入力変更時に何を再生成・保持するかを明確にする。
変更を適用するまで現在の実験状態を破壊しない設計を優先する。

【Canvas可視化】
青＝協力者、赤＝裏切り者を基本とする。
各セルの色が世代ごとに変わり、協力集団の島、境界の動き、
侵入・崩壊などを観察できるようにする。
色覚差に依存しない凡例や補助表示を設ける。

住民選択時には、座標、現在戦略、局所得点、近隣構成、
直前の戦略変更理由を表示する。
必要なら描画を間引いて速度を保つが、シミュレーションの
計算結果と描画状態が食い違わないようにする。
DPR、画面サイズ変更、停止・再開、タッチ操作を考慮する。
装飾表現を追加する場合も数学的状態と混同しない。

【統計と観察】
・協力率の時系列
・協力者数／裏切り者数
・各戦略の平均利得
・世代ごとの戦略変更数
・協力者集団の規模や境界などの空間統計を可能な範囲で追加
・現在状態と初期状態の比較
グラフと数値は必ず同じ確定世代のデータを参照する。
集団構造と協力率を別指標として扱い、因果関係を断定しない。

【比較実験】
同じ初期配置とseedを使い、設定だけを一つ変える比較モードを
追加する。左右並列表示または同等の見やすい比較UIとする。
両条件の世代数、計算規則、統計の整合を保持する。
変更されたパラメータを明示し、比較条件が崩れた場合は
警告または再初期化を行う。

【プリセット】
少なくとも6種を検討する。
1. ランダム混在
2. 協力者の島
3. 裏切り者の侵入
4. 近傍4／8比較
5. 突然変異のある社会
6. 模倣規則の比較
各プリセットの初期配置、パラメータ、seedを定義し、
期待する現象は仮説として表示する。
必ず特定の結果になると誤って保証しない。

【4段階教材】
第1段階：協力と裏切りの利得を直感的に理解
第2段階：隣人から得点を計算する仕組み
第3段階：局所的な模倣から模様が形成される仕組み
第4段階：条件比較による協力の成立・崩壊の考察

数式、記号の読み方、日本語説明、実際のCanvas表示を連動させる。
R,T,P,S、利得合計、模倣確率などを教材内で説明する。
現実の人間社会を単純な二戦略で説明し尽くせるわけではないこと、
この作品が抽象的な数理モデルであることを明記する。
