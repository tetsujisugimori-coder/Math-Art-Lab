作品メニューの「016 · 協力の格子」で開く、空間的な2戦略ゲームの実験室。

## モデルの契約

- C=1（青・斜線）、D=0（赤・点）。全セルに1人、移動・空き家・自己対戦なし。
- 利得：C/C=R、C/D=S、D/C=T、D/D=P。既定T=5,R=3,P=1,S=0。
- T>R>P>Sを厳密PD、T>R>P=Sを弱いPDと表示。それ以外は一般ゲームとして値を補正せず実行。
- 追加条件2R>T+Sは独立に判定。PDの順序条件と混同しない。
- 4近傍または8近傍。固定端は外を除外、周期境界は折り返す。
- 利得合計を標準とし、近隣人数で割る平均を選択可能。固定端では次数差に注意。
- 全セルの旧得点と旧戦略から次状態を計算し、一括反映。その後、確定状態の得点・統計を再計算。
- 最良模倣：自分と近隣の最高得点。自分が最高点なら維持。自分より高い最高点が複数なら行優先・列優先の最小セル番号を選択。この決定的同点処理には方向性がある。
- Fermi：近隣1人を一様に抽出。W=1/(1+exp((πᵢ−πⱼ)/K))でその旧戦略を採用。K>0。同点1/2。温度が高いほど得点差の影響が小さい。指数の符号で分岐し、正の大きな指数を計算しない。
- 突然変異：模倣とは別に各セル確率μで戦略を反転。変更数は旧状態と最終状態の差、突然変異数は反転処理の数。
- 乱数：32bit整数ミキサー。seed・旧世代・セル番号・用途でキーを作成。候補選択、模倣採否、突然変異の3用途。走査順・描画・速度に依存しない。暗号用乱数ではない。
- 初期ランダム配置はround(n²×初期協力率)人のCをseed付きFisher–Yatesで配置。島は中央約1/4、侵入は全Cの中央1人だけD。この2配置は割合入力を使わない旨を表示。

## 状態と比較

設定編集とプリセット選択は候補入力のみ。適用で停止して0世代から再生成。エラーでは実験状態を保持。
初期化は適用済み設定と初期配置を復元し、未適用の候補入力を保持する。速度だけ即時反映。

比較はAの適用済み条件から近傍・規則・T・温度・突然変異率・境界・得点集計の一つだけを変更。
両側を同一初期配列・seedの0世代から開始。同じキーの乱数を使用し、各ステップで両側を更新してから描画。
統計は各側の確定状態、初期統計はAの条件で評価。近傍変更時の連結・境界指標の定義の違いを明示。
比較終了はAを保持。通常の設定適用で比較を解除（比較用プリセットの場合は再構築）。

## 表示と教材

Canvas（A/B、必要時に初期配置）・SVG協力率・HTML統計表を使用。描画はモデルを変更しない。
現在のC/D数、戦略別平均利得、変更数、突然変異数、最大C連結成分、C–D境界ペアを表示。
セル選択はクリック／タップ／矢印キー／行列フォーム。現在の局所得点と直前世代の採用理由を区別。
青斜線・赤点は戦略、枠は選択／近隣。格子の色を装飾で変えない。

4段階教材は利得→近隣得点→同期模倣→一条件比較。現在状態と選択住民へ連動し、切替で状態を変更しない。
記号ボタンでR/T/P/Sの読み方・役割・適用値を説明。抽象模型の限界を画面に明記。

6プリセットの全数値・配置・seed・比較条件は `src/cooperation.ts` の `presets` に定義。
画面上の期待現象は仮説であり、存続・崩壊などの特定結果を保証しない。

## 可視化設計・コスト

| 層 | 目的と符号化 | フォールバック・検証 |
| --- | --- | --- |
| Canvas格子 | 各セルのC/D、位置、選択近隣。最大2実験×6400セル | HTML観察文、行列入力、統計表。実画素の戦略を独立読み取り |
| SVG時系列 | 横軸世代、縦軸協力率0〜100%。実線A・破線B、平滑化なし | 現在値の文章・統計表。端点と画素から算出した率を照合 |
| HTML比較表 | 初期Aと現在A/Bの確定世代・実数 | キーボード到達可能な局所スクロール領域 |

data-visualizationルーター、Canvas2D・testing専門ガイドを適用し、ローカルで再点検。独立レビューとは呼ばない。
既存のTypeScript/Vite・共通作品選択・CSS・Playwright構造を再利用し、新ライブラリなし。
履歴は直近600点、初期配列1つ、直前判断配列1つ。世代ごとの全格子を履歴に蓄積しない。
CanvasはDPR上限3、スマートフォンで比較を縦並び、デスクトップで左右。表と数式だけ局所スクロール可能。
選択はスクリーン座標をCanvas矩形で正規化。タッチはページスクロールとブラウザ拡大を許可。
停止・非表示・設定適用・作品離脱でタイマーを解除。ResizeObserverとDOMイベントは離脱時破棄。
reduced-motionで初期自動再生なし、設定変更時停止。ユーザーが明示的に開始することは可能。
永続化・URL保存・音・粒子・装飾アニメーションは追加しない。P0/P1と記憶量制限を優先。

## 出典と原著との差

- [Szabó & Tőke, Evolutionary prisoner's dilemma game on a square lattice (1998)](https://arxiv.org/abs/cond-mat/9710096)

結果から現実社会の因果関係や政策の有効性を断定しない。
