【3. 作品の基本イメージ】

作品名：
波紋の万華鏡

コンセプト：
複数の波が生む干渉と対称性を、
光の花として観察する。

基本的な画面は、暗い背景の中央に
円形の模様が浮かび上がる構成です。

円周上に等間隔で配置された複数の波源から
波が広がり、互いに重なり合います。

その結果、花弁状、星状、環状などの
複雑な干渉模様が現れます。

波源の数や波長を変更すると、
模様が連続的または段階的に変化します。

色彩は青、紫、シアン、ピンク、金色などを
中心とした発光表現を想定します。

作品全体を華やかにして構いませんが、
数学的な計算結果とは無関係な装飾だけで
模様を成立させてはいけません。

参考イメージのステンドグラス風表現は
必須ではありません。

数学的な干渉模様を中心に、
必要に応じて透明感、残光、発光表現を
追加してください。

【4. 数学モデル】

基本モデルは、同じ振動数を持つ複数の
円形波の重ね合わせとします。

観測位置を p=(x,y)、
波源の位置を p_j=(x_j,y_j) とします。

波源までの距離：

r_j = √((x-x_j)²+(y-y_j)²)

各波源の変位：

u_j(x,y,t)
  = A_j cos(k r_j - ωt + φ_j)

合成変位：

u(x,y,t)
  = Σ[j=1..N] u_j(x,y,t)

ここで、

N：波源の数
A_j：各波源の振幅
k：波数
ω：角振動数
φ_j：各波源の初期位相
t：時間

とします。

波数と波長の関係：

k = 2π / λ

波源を円周上に配置する基本形：

x_j = R cos(2πj/N + θ)
y_j = R sin(2πj/N + θ)

R：波源配置の半径
θ：配置の回転角

実装では添字の始点を明確にし、
N個の波源を重複なく生成してください。

同じ振動数を持つ波の包絡振幅は、
以下から求められます。

C(x,y)
  = |Σ[j=1..N] A_j exp(i(k r_j + φ_j))|

強度相当量：

I(x,y) = C(x,y)²

必要に応じて正規化します。

ここでのIは、教材用の強度相当量です。
実際の光学系の照度や水面波のエネルギーを
厳密に再現するモデルだとは説明しないで
ください。

また、今回の基本モデルでは距離による
振幅減衰を省略します。

これは鑑賞性と数学的な理解を優先した
理想化モデルであり、画面内で明記します。

距離減衰を追加する場合は、数式・教材・
描画計算・検証を一致させてください。

【5. 対称性の仕様】

初期状態では、各波源の振幅と位相を
同一とします。

波源を円周上に等間隔配置することにより、
N回回転対称性を持つ干渉模様を生成します。

波源の数Nを変更すると、基本的な対称性が
どのように変化するか観察できるように
してください。

ただし、N回回転対称性と、
実際に見える花弁の本数を
同じものとして説明しないでください。

花弁状の明暗構造は波長、配置半径、
表示範囲、強度の可視化方法にも依存します。

描画結果と教材説明が一致するようにします。

追加の発展機能として、特定の波源の
位相をずらし、対称性を意図的に崩す
モードを検討してください。

このモードを実装する場合は、
基本対称モードとの違いを明示します。

【7. 表示モード】

次の表示を用意してください。

A. 瞬間変位

時間とともに変化する合成波の変位uを
表示します。

正負の変位を区別できる色彩を使用します。

B. 包絡振幅

時間に依存しない包絡振幅Cを表示します。

どこで波が強く重なり、どこで打ち消し合うか
分かるようにします。

C. 干渉の強度

C²から計算した強度相当量を表示します。

高い値の部分が発光するような
芸術的表現を取り入れて構いません。

ただし、強度と色の対応を凡例に示します。

D. 波源・対称性ガイド

各波源の位置、円周、中心、対称軸などを
確認できる補助表示です。

これらを必要に応じて重ねて表示します。

描画色は可視化上の表現であり、
物理的な波長そのものの色とは
区別してください。

【8. 数式と図の連携】

数式の各要素を選択すると、
図の対応部分を強調してください。

例：

N：
波源をすべて強調する。

R：
中心から各波源までの距離を示す。

λ：
代表的な波源の波長を図示する。

θ：
波源配置の回転方向を示す。

r_j：
観測点から対象波源までの距離を示す。

A_j：
対象波源の振幅を説明する。

φ_j：
位相差による波のずれを示す。

C：
観測点の包絡振幅を示す。

数式の読み方を日本語で説明してください。

例：

Σ：
シグマ。指定された範囲の値を全部足す。

φ：
ファイ。波の開始位置のずれを表す位相。

ω：
オメガ。振動の速さに関係する角振動数。

λ：
ラムダ。波の山から次の山までの距離。

数学記号を見ただけでは意味が分からない
利用者でも理解できる教材にしてください。

数式から図を強調する操作は、
マウス、タッチ、キーボードで利用できる
方法を採用してください。

【9. 4段階の教材】

既存作品と同様に、4段階の教材を用意します。

第1段階：ひとつの波

波源を1つ表示します。

円形の波がどのように広がるか、
波長と振幅を変えながら観察します。

第2段階：波を重ねる

波源を2つに増やします。

重ね合わせによる強め合いと
弱め合いを確認します。

既存「波紋の対話」と関連付けても
構いません。

第3段階：対称性を作る

波源を円周上に等間隔配置します。

3、4、5、6個などに変えると、
模様の対称性がどう変化するか
観察します。

第4段階：万華鏡を完成させる

波源数、半径、波長、回転角、色彩を
自由に組み合わせます。

瞬間変位、包絡振幅、強度の違いも
確認できるようにします。

教材の終了時には、教材開始前の
作品設定と操作状態を復元してください。

作品鑑賞と教材の状態管理を分離し、
他の作品に影響しないようにします。
