# ハーモノグラフ教材モードの確認画像

Chromium、動きを減らす設定あり、教材の初期設定、停止して0.25秒送りを20回（t=5秒）行った同じ状態。段階変更で時刻と係数を維持している。PCは1280×1000、狭幅は375×1000。stage-columnだけを切り出し、説明・時刻・操作と図の対応を残した。

- [左右の往復・範囲（PC）](1280-stage-1.png)
- [上下と短い軌跡（375px）](375-stage-2.png)
- [奥行きと短い軌跡（375px）](375-stage-3.png)
- [0秒から蓄積した軌跡（PC）](1280-stage-4.png)
- [段階・係数・数式の操作パネル（375px）](375-controls.png)

実画像を開いて、現在の白い点、軸名、振幅と端から端の区別、短い軌跡と蓄積の違い、狭幅での数式・ボタンの収まりを確認した。WebKitでもE2E内で同じ段階と3幅の撮影・操作を行う。実機iPhone Safariの確認ではない。
