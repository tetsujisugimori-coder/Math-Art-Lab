## モデルと離散化

```
∂u/∂t = Du ∇²u − uv² + F(1−u)
∂v/∂t = Dv ∇²v + uv² − (F+k)v
Du=0.16, Dv=0.08, Δx=1, Δt=1
L(a)[x,y] = a[x−1,y]+a[x+1,y]+a[x,y−1]+a[x,y+1]−4a[x,y]
u_next = u + Du L(u) − uv² + F(1−u)
v_next = v + Dv L(v) + uv² − (F+k)v
```

格子は128×128。外側の隣接先を当該境界セル自身とするゼロ流束境界。角では2つの隣接先が自身になる。Float64Arrayの現状態から別バッファに全セルを計算し、検査後に交換する。Workerの1要求は1〜32ステップ。観察と予測はWorkerと同じ適用済み格子・設定・演算を参照する。全濃度の非有限値または[0,1]外を異常として検出し、最後の確定済みチャンクを保持して停止する。異常がチャンク途中で起きた場合、そのチャンク全体を確定しない。演算の切り詰め・反応項の省略は通常モードで行わない。

uは補充物質、vは自己触媒的に増える物質。uv²はuを減らしvを増やす。Fはu補充とv希釈、kは追加除去。連続偏微分方程式そのものの厳密解ではなく有限格子と時間刻みの近似。名称は比喩であり、チューリング元論文・厳密な生物模様再現・一般的なチューリング不安定性の証明とはしない。

初期条件はu=1,v=0に、中心(64,64)、(38,44)、(89,83)の半径3の円（距離二乗≤9、各29セル）をu=0.5,v=0.25へ上書き。乱数は使わない。種追加も同じ上書きで、重複しても量は増やさない。種消去は全格子u=1,v=0、step=0。一様場はこの完全な式の不動点。

参考：[Karl Sims, Reaction-Diffusion Tutorial](https://www.karlsims.com/rd.html)。資料はDu=1,Dv=0.5、中心−1／隣接0.2／対角0.05の9点重みを例示している。本作はIssueの5点差分と係数を優先し、資料の画像と同一とは扱わない。

## 操作と状態管理

- Fは0.01〜0.08、kは0.045〜0.07。候補と適用値を分け、空欄・非有限・範囲外・0にアンダーフローする非ゼロを拒否する。適用時は初期状態で停止。不正入力は計算状態を変更しない。
- 再生は16整数ステップのチャンクを約50ms間隔で要求。壁時計との厳密同期ではなく、端末性能により進行速度は遅くなる。1ステップは厳密に1回。早送りは1〜10000の整数、最大32ずつに分割。停止・中断で未確定チャンクを捨てる。
- 初期状態へ戻すと適用F/kを保ち固定3種へ。設定を初期値へは斑点のF/kと種・選択座標を戻す。種追加は停止し、格子とステップを保って局所上書きする。
- 図内のクリック・タップ・ドラッグ、数値座標（0〜127の整数）、フォーカス後の矢印移動とEnterで追加。Pointer captureを使い、外側の座標・pointercancel・capture喪失後の移動は追加しない。clickハンドラによる二重追加はない。図内はtouch-action:none、図外でスクロール。
- vを固定尺度0〜0.5で色へ写像。描画色だけを正規化する。白黒高コントラストへ切替可能。観察数値は常に併記。白枠が観察セルで、∇²選択は近傍枠も表示する。
- u/v/∇²/uv²/F/kボタンをホバー・タップ・Tabで選択すると説明・適用値・観察欄・図のマーカーを強調。解除／Escapeあり。式は安全な固定テキストを使用する（既存のMathMLレンダラーは文字列をmtext化する方式のため、本作では読み上げ可能なUnicode表記を採用）。
- 教材は①拡散のみ、②反応・補充・除去のみ、③完全式、④同じ種でのパラメータ比較。①②は通常計算と異なる実験と明記。段階変更は初期状態へ。④の比較ボタンは選択プリセットで必ず初期状態から2000ステップ。教材開始前の格子全体・ステップ・適用値・候補・表示・選択・強調・再生状態を退避し、閉じる／Escapeで戻す。
- リセット・設定変更・教材終了・中断で世代を更新し古いWorker応答を拒否。非表示・途中のreduced-motion有効化では停止し、復帰で自動再開しない。教材中にこれらが発生した場合は復元後も停止。通常の初期表示も停止（種の初期濃度を観察するための実装判断）。明示再生はreduced-motionでも可能。
- 作品切替はWorkerをterminateし、タイマー・文書イベント・media queryイベント・Canvasバッファを破棄。rAFやobserverは使わない。Canvas／Worker非対応時は説明し計算を無効化する。

## 独立した数学基準

3×3の中央だけu=1、他は0の拡散実験の1回更新は、中央0.36、上下左右0.16、角0。総量1で、入力配列は不変。隅のv=1は中央0.84、2隣接0.08となる。

3×3のu=1,v=0に中央u=.5,v=.25を置く完全式の手計算：Lu=2、Lv=−1。拡散寄与(.32,−.08)、反応.03125、補充.015、除去−.023。次の中央u=.80375,v=.17825、隣接u=.92,v=.02。期待値は実装関数で生成しない。均一なu=.5,v=.25の反応のみはu=.48375,v=.25825。128格子の初期中心も近傍が同濃度のため完全式1回でこの値になり、E2Eでも直接検査する。

Vitestで境界、均一不動点、符号、入力拒否、二重バッファ、決定性、種、異常停止、世代を検証。32回と13+19回の格子全体の完全一致も確認。
