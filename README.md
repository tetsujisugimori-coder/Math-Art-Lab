## Experiment 006: フラクタルの双子（Mandelbrot × Julia）

「作品」から「006 · フラクタルの双子」を選ぶ。同じ複素数の式 `z(n+1)=z(n)²+c` を、左は **z(0)=0を固定してcを変える** マンデルブロ集合、右は **cを固定してz(0)を変える** ジュリア集合として比較する。デスクトップは左右、780px以下は上下配置。右の暗い領域は充填ジュリア集合Kcの有限反復近似で、数学的なジュリア集合JcはKcの境界である。

- 左をクリック／タップすると十字のcを選び、右を再計算する。右の丸は数列表で調べる出発点z(0)。両画面の軸・選択点・適用値を確認できる。cの実部／虚部は各−4〜4（境界を含む）で数値入力も可能。表示範囲は選択範囲より広く移動・縮小できる。範囲外を選ぶと図の直下に未適用の理由と保持中の値を示し、c・Julia画像・入力中の候補を変えず再計算もしない。Enterによる中央選択も同じ判定。「設定を適用」前は候補値で、不正な入力や倍精度で0にアンダーフローする非ゼロ入力は拒否し、直前の有効な図を保つ。
- 各画面は独立してドラッグ／1本指で移動、ホイール／2本指ピンチで位置を基準に拡大縮小できる。明示ボタンもある。図にフォーカスして矢印で移動、Enterで中央を選択、+/−で拡大縮小、Homeで範囲を戻す。ページは図の外でスクロールする。表示中心の実部／虚部は±16、拡大は0.25〜100万倍まで。これは倍精度と有限画素を考慮した製品上限であり、数学的な正確性の保証ではない。
- 最大反復回数Nは初期200、50〜500。増やすと遅れて発散する点をさらに観測できるが、有限回で未観測でも集合への所属は証明できない。暗色はNまで発散未観測、明色は閾値を初めて超えた反復回数の32回周期の配色。色だけで分類せず、複素数の数列表と判定を併用する。
- プリセットは「枝の渦」c=−0.8+0.156i、「円の基準」c=0、「二周期」c=−1、「粒の群れ」c=0.285+0.01i。cのみ切り替え、Nと表示範囲は保つ。c=0では充填集合が単位円板、その境界が単位円。c=−1、z(0)=0では0→−1→0の周期を確認できる。「初期設定に戻す」は両表示範囲を含めて戻す。
- 4段階教材は①複素数の世界、②反復計算、③発散と境界、④二つの集合の関係。数列表を1反復ずつ進める（最大16、閾値超過で停止）。教材を閉じる／Escapeで開始前のc・出発点・N・表示範囲・数列表の段階・記号強調を復元する。教材内から閉じた場合は開始ボタンへフォーカスを戻す。
- c・z(0)・二乗・N・発散半径Rの記号ボタンはホバー、タップ、Tabで選べる。数式本体のc・z²もクリック／タップでき、同じ強調状態で式・説明・対象の図を示す。強調だけでは再計算しない。計算条件と数式は同じ状態を参照し、表示は有効数字10桁の約値。小さい非ゼロ値を表示上の0に丸めない。

ピンチから1本指へ移ると、残った指の位置と現在の表示範囲を基準に移動を続ける。ピンチ後の指離しをc選択には扱わない。cancel／capture喪失は該当する指だけを解除し、全指が離れた後の新しいタップから選択できる。[PR #19の修正検証記録](docs/fractal-twins/review-19.md)を参照。

発散判定は厳密な `|z(n)|>R`。左はz(0)=0に対してR=2、右は任意の許容cに十分な `R=max(2,|c|+1)` を使う。単にJuliaにも常にR=2を使うことはしない。[根拠・独立基準計算・GUI画像](docs/fractal-twins/README.md)を参照。

Canvas 2Dへ、2つのWeb WorkerでJavaScript倍精度計算した画素を転送する。GPUシェーダーの単精度計算は使用しない。行単位で処理を区切り、最新要求だけを確定する。古い要求は破棄し、計算中は古い画像を消して待機状態を表示する。cだけの変更では左、数列のステップや記号強調では両図とも再計算しない。DPR最大1.5、各辺640画素、RGBA配列1枚最大1.5625MiB。これはブラウザ全体のメモリ上限ではない。非表示タブでは計算を中断し、作品切替時にはWorker・イベント・observer・タイマー・描画バッファを解放する。再選択は既存作品と同じく初期設定から開始する。自動アニメーションはない。

浮動小数点丸め、有限反復、有限画素の制約があり、画面拡大や色分けは厳密な所属・自己相似性の証明ではない。WindowsのChromium／WebKit検証と実機iPhone Safariは区別する。実機の複数指操作、スクリーンリーダー、低性能端末、GPU負荷・実メモリ総量・電池・熱・長時間負荷は未検証。Canvas 2D／Web Workerを利用できない環境では説明を表示する。依存関係、既存5作品の数学、公開URL・Vite base・Pagesの公開条件は変更しない。

## Experiment 005: カオスの蝶（Lorenz Attractor）

「作品」から「005 · カオスの蝶」を選択する。暗い3D空間にローレンツ方程式の数値軌道が伸びる。A：標準の蝶、B：微小差分比較、C：ρ=14からのパラメータ変化を用意した。Cを含め、任意の設定が蝶形・カオスになるとは限らない。

```
dx/dt = σ(y − x)
dy/dt = x(ρ − z) − y
dz/dt = xy − βz
σ=10, ρ=28, β=8/3, (x₀,y₀,z₀)=(1,1,1)
```

固定刻みRK4（Δt=0.005）で倍精度の位置を計算し、単精度の線分として描く。計算済みの同じデータから表示時刻を選ぶので、描画フレームの頻度や再生速度は数値解を変えない。初期設定は12,000点、t=0〜59.995。Bは初期xにδ=0.00001を加え、Aと同じ係数・RK4・刻みで計算する。実線・丸い点Aと破線・菱形の点B、同時刻の3次元距離dで比較する。距離は離れたり近づいたりし、一定割合で増え続けるとは説明しない。

- 再生／一時停止、停止中の1ステップ（0.005）、最初から、完成形表示を使用できる。完成形から再生するとt=0に戻る。「最初から」は停止状態を保ち、完成形からは再生する（reduced-motion時は停止）。
- ドラッグ・タッチ、図にフォーカスして矢印キー、左右／上下ボタンで回転。拡大・縮小と視点リセットは独立したボタン。数式記号はホバー・タップ・Tabで選び、対応する式・適用値・入力・図の座標軸または注記を強調する。Escape／解除ボタンで解除する。
- 「係数・初期値を調整」でσ=1〜20、ρ=0〜50、β=0.5〜6、初期x/y=−30〜30、初期z=−30〜60、δ=10⁻⁸〜0.1、点数=1,000〜24,000を入力し「設定を適用」。推奨は標準値。範囲は数学的なカオスの条件とは別の実装上の制限。点数16,000超では負荷を注意表示する。
- 設定適用は古い軌道を破棄してt=0から再計算し、停止中なら停止、完成形なら新しい完成形を保つ。不正値・非有限値・計算中の過大値は拒否し、図と適用値を直前の有効な設定に保つ。入力欄は未適用の候補値として残す。プリセットは速度と視点を保ってモデル設定全体を切り替え、「設定を初期値へ」は速度も戻す。
- 4段階教材は「3本の式→軌跡の生成→カオスの観察→フラクタルとの関係」。現在位置と正規化した方向矢印v、各変化速度を表示する。教材を閉じると開始前の設定・速度・進行へ戻る。作品切替は既存作品と同様に初期状態へ戻す。

有限時間の軌跡には過渡状態も含まれ、アトラクター全体やその厳密な表現ではない。拡大は自己相似性の証明ではなく、フラクタル次元の推定は実装しない。離散的な反復・発散判定で調べるマンデルブロ集合／マンデルバルブとの相違も教材に記した。線は有限標本間の直線、点と矢印のサイズは表示用で、残光による軌跡の追加はない。長時間の数値解の一致や一般的な予測可能期間を保証しない。

DPR最大1.75・描画バッファ各辺最大1,600px。非表示タブは時刻・描画を停止し、復帰時に非表示期間を消費しない。reduced-motionでは静止した完成形から開始し、途中で有効になると停止する。作品切替時はrAF・ResizeObserver・イベント・GPU資源を解放する。WebGL2が必要で、開始失敗時は説明を表示する。Pagesの配下パスと既存CIをそのまま使用する。検証条件・測定値・制約は [確認記録](docs/lorenz/README.md) を参照。

数学モデルの一次資料：[Lorenz (1963), Deterministic Nonperiodic Flow](https://journals.ametsoc.org/view/journals/atsc/20/2/1520-0469_1963_020_0130_dnf_2_0_co_2.xml)。実機iPhone Safari、スクリーンリーダー、低性能GPU・電池・熱・長時間負荷は未検証。

## Experiment 004: 光の結び目（Luminous Knot）

「作品」から「004 · 光の結び目」を選ぶ。二つの周回を組み合わせ、一本の光がトーラス結び目を描く。初期値は `R=3, r=1, p=2, q=3`。三つ葉 T(2,3)、トーラス結び目 T(3,5)、五葉 T(2,5) の3プリセットを比較できる。T(3,5)は五葉結び目とは別の種類。

```
x(t) = (R + r cos(qt)) cos(pt)
y(t) = (R + r cos(qt)) sin(pt)
z(t) = r sin(qt),   0 ≤ t ≤ 2π
```

`t`は曲線上の位置を決める媒介変数（rad）。`p`は中心軸の周囲の回転数、`q`は断面方向の回転数で、同じtから同時に決まる。`R`は原点Oから断面の中心Cまでの距離、`r`はCから曲線上のPまでの距離。rは光の線の太さではない。曲線の中心線が `(√(x²+y²)−R)²+z²=r²` を満たす。

- 再生／一時停止で位置と描画済みの線を保持する。「最初から描き直す」は設定を保ってt=0へ戻り、停止中は停止、完成形からは再生する。「完成形を表示」は全曲線を表示する。
- 位置tのスライダーを動かすと停止し、その位置の座標とガイドを確認できる。描画速度は0.1〜2 rad/秒で、形や標本精度を変えない。
- 「かたちを調整」でp・q・R・rを入力し「設定を適用」。p・qは1〜9の互いに素な正の整数、Rは1〜6、rは0.2〜2.5、かつR>r。表示精度のためR−r≥0.1も必要。不正な候補は補正せず拒否し、図と数式は直前の有効値を保つ。pかqが1なら、ほどくと輪になる自明な結び目も観察できる。
- 形やプリセットを変更すると描き始めへ戻る。プリセットはp・qを切り替え、R・rは維持する。停止中は停止、完成形表示中は新しい完成形を保つ。「設定を初期値へ」は係数と速度を初期化し、視点は「視点を戻す」で別に戻す。
- 図の中をドラッグ・タッチ、または図にフォーカスして矢印キーで回転する。「左右に回す」「上下に回す」も使える。ページは図の外でスクロールする。
- 「数式と図の対応・4段階の解説」を開き、tと周回→二つの回転→閉じる条件→投影上の交差を確認する。6種類の「図で見る」で中央の円、断面の円、方向の矢印、R／rの距離を示す。O・C・Pのラベルと周回数も表示し、色だけに頼らない。再選択・解除・Escapeで戻る。パネル内からの解除は元の数式ボタンへフォーカスを戻す。「図形を確認」「選択中の数式へ」は明示的に図と操作を往復する。
- 補助トーラスは半透明で表示できる。光の管には表示用の細い厚みがあるが、その中心は数式どおり。画面上の交差は空間内の接合ではない。「線のみ（軽量）」では光の縁を省く。

OSの動きを減らす設定では静止した完成形から開始し、途中で有効にした場合はその場で停止する。手動再生は可能。背景タブでは時刻と描画を止め、復帰時に経過分を一気に進めない。作品切替時はGPU資源・イベント・描画ループを解放し、再選択時は既存作品と同じく初期設定から開始する。

標本は設定に応じて1,024〜2,304区間、表示用の管は断面8分割。数式の曲線を有限の線分・面で近似し、描画位置も標本に合わせて進める。DPRは最大1.75、描画バッファの各辺は最大1,600px。ライトテーマはOS／ブラウザ設定に追従し、作品の背景は暗いまま保つ。WebGL2が必要で、利用できないときは説明を表示する。実機iPhone Safari、スクリーンリーダー、低性能GPUは未検証。R−rが小さい許容設定では、形を覆わないよう光の管も細くなり見えにくい場合がある。[確認画像と条件](docs/knot/README.md)を参照。

分類の確認：[Knot Atlas 10₁₂₄ / T(5,3)](https://katlas.org/wiki/10_124)、[五葉T(2,5)の研究論文](https://arxiv.org/abs/2105.12102)。pとqを交換したトーラス結び目は同じ種類であるが、ここで生成する座標と見た目は指定したp・qの順序に従う。

## Experiment 003: 光の花園

「作品」から「003 · 光の花園」を選ぶ。暗い背景に、中心の金色から珊瑚色・ピンク・紫・水色へ広がる光点を配置する。初期設定は1,200点と黄金角。正面から見る平面の作品で、背景粒子や点どうしを結ぶ線は描かない。

配置は点番号n=0から `θₙ=nα`、`rₙ=c√n`、`xₙ=rₙcos(θₙ)`、`yₙ=rₙsin(θₙ)`。角度αは度で入力し、計算時にラジアンへ変換する。黄金角は `180(3−√5)` 度を使い、137.5度には丸めない。c=0.14は配置の広がりで、粒の見た目の半径とは別の値。sin・cosは向きと半径をx・yへ変換し、外への広がりはrの式が決める。

- 「一時停止／再生」で表示済みの点を保持して止め、続きから再開する。「1点追加」は停止中に使える。
- 「最初から」は設定を保って0点へ。停止中なら停止を保ち、完成形からなら再生する。「完成形」は全点をすぐに表示する。
- 総点数は1〜3,000、角度は0〜360度、成長速度は1〜600点/秒。角度はスライダー・数値入力・±0.01°ボタンで変更でき、スライダーの矢印キーは0.001°刻み。
- 「黄金角」「120°」「90°」「黄金角の近く · 137.3°」を比較できる。120°は3方向、90°は4方向へ並び、多数の点が重なると線状に見える。黄金角は同じ向きへ重なりにくいが、完全な均一性や螺旋の本数は保証しない。
- 角度変更では表示点数と再生状態を保つ。総点数を減らすと上限で打ち切り、完成形表示中の総点数変更は新しい完成形を表示する。表示範囲は総点数から決めるため、成長中に自動で拡大縮小しない。色は設定した総点数に対する点番号で固定し、成長中は変えない。

「置き方を見る」で、作品と別の教材に入る。①番号と順番、②中心からの2本の方向と反時計回りの角度、③中心からの半径、④点を増やして全体を見る、の4段階。最初は6点で停止し、段階1〜3は最大12点・3点/秒に限定する。段階4で総点数と速度を操作できる。段階1〜3は少数点の進行を共有し、段階4の点数と再生・停止・完成状態は別に保存する。段階4を離れている間は進まず、戻ると続きから再開する。初めて段階4へ進むときは少数点の点数を引き継ぎ、12点への到達だけで全体の完成形にはならない。黄金角を含む角度の変更は教材でも可能。「図形を確認」で明示的に図へ移動し、選ぶだけでは自動スクロールしない。

「数式と現在の点」では、最後に置いた点のn、α、c、半径・座標を対応させる。表示は約値で、描画は丸め前の値を用いる。n=0は中心なので図形上の方向を持たず、n=1の角度解説はθ₀=0の基準方向から示す。r=c√nは面積の増え方に合わせた配置で、隣り合う粒の距離が常に等しいという意味ではない。

「作品へ戻る」またはEscapeで、入る前の作品設定・表示点数・再生状態へ戻る。教材中に作品の進行は増えない。教材内の段階ボタンからEscapeで戻る場合は入口へフォーカスを復帰する。OSの「動きを減らす」では作品は静止した完成形から、教材は停止状態から始める。設定を途中で有効にした際も停止し、手動での再生は可能。背景タブでは描画と時計を止め、復帰時に隠れていた時間を消費しない。

描画は既存のThree.jsで、生成済みの点バッファの表示範囲を進める。DPRは最大2、描画バッファの各辺は最大1,600px。画面サイズ変更後は120msの操作待ちを経て必要な解像度でGPUコンテキストを再作成し、古いコンテキストを解放する。Windows WebKitでの再割当て後の空白を回避し、初期解像度の引き伸ばしを残さない。リサイズ中は一時的に前の画像が伸縮するが、落ち着いた後に更新される。実機iPhone Safari、スクリーンリーダー、低性能端末の測定は未実施。[確認画像と条件](docs/garden/README.md)を参照。

## Experiment 002: 光のハーモノグラフ

「光の糸で、空中に花を織っていく」。6つの減衰する正弦波がつくる3次元の軌跡を、暗い空間へ少しずつ描く。初期表示は「四葉の光冠」。ページ上部の「作品」から既存のFractal × Waveにも切り替えられる。作品を切り替えると、その作品の初期状態へ戻る。

「四葉の光冠」「光の繭」「星編みの籠」の3プリセットを用意する。「一時停止」は位置と軌跡を保持し、「再開」はその続きから描く。「最初から描き直す」は設定を保って始点へ戻す。停止中なら停止を保ち、完成形からなら再び描き始める。「完成形を表示」は現在の設定の全軌跡をすぐに表示する。

「かたちを調整」で次の値を操作できる。設定やプリセットを変更すると描き始めへ戻り、停止中は停止、再生中は再生を保つ。完成形表示中は新しい設定の完成形を表示する。「設定を初期値へ」はプリセットと形状設定・再生速度を初期値へ戻す。視点は別の「視点を戻す」で戻せる。

| 操作 | 実際に変わる係数 |
| --- | --- |
| yの周波数倍率 | yの2項の角周波数だけを0.8〜1.2倍にする |
| 第2項の位相ずれ | x・y・zそれぞれの第2項の位相へ−3.14〜3.14 radを加える |
| 共通の減衰 d | 全6項の減衰係数。0〜0.02 /s |
| zの振幅倍率（奥行き） | zの2項の振幅だけを0〜1.6倍にする。0なら平面 |
| 描く時間範囲 T | 0〜T秒を描く。Tは20〜160秒 |
| 再生速度 | 作品内の秒 / 実時間の秒。1〜12。形・周波数・標本点は変えない |

各座標の式は `q(t) = A₁ exp(−dt) sin(f₁t+p₁) + A₂ exp(−dt) sin(f₂t+p₂)`（qはx・y・z）。振幅Aは揺れの大きさ、周波数fは揺れの速さ（ここでは角周波数rad/s、Hz換算はf/2π）、位相pは揺れ始める位置のずれ、減衰dは時間とともに揺れが小さくなる度合い。tは作品内の秒であり、再生速度とは区別する。減衰・周波数のずれ・3次元の組合せがあるため、整数比だけで閉じるとは説明しない。

「数式と図の対応」には、実際の軌跡計算に渡した係数から作るMathMLの現在式を表示する。長い式は領域内だけを横スクロールでき、はみ出す領域にはTabで移動できる。「図で見る」で選んだ座標軸、先端Pの軸への直角投影Q、原点からQへの成分線を表示する。下の成分グラフも同じ標本点を用い、現在の位置を示す。色に加えて、軸名・点・実線・破線・数値・選択枠で対応を識別する。原点や軸は作品と同じ座標変換を使う。解説は再選択・解除ボタン・Escapeで解除でき、パネル内からの解除では元の数式ボタンへスクロールせずにフォーカスを戻す。

ドラッグや図形内のタッチで回転し、ホイールまたは「拡大」「縮小」でズームできる。「斜めから見る」「視点を戻す」もキーボードで操作できる。図形の外は通常のページスクロールとして扱う。モバイルでは「図形を確認」「選択中の数式へ」で明示的に往復でき、解説を選ぶだけでは自動スクロールしない。

OSの「動きを減らす」では静止した完成形から始める。「最初から描き直す」も停止状態から始まり、利用者が「再開」を選べる。背景タブでは描画・時刻更新を止め、戻ったときに隠れていた時間をまとめて進めない。完成後・停止中は操作やサイズ変更がある場合だけ描画する。

軌跡は設定変更時に一度生成し、再生中は生成済みBufferGeometryの表示範囲を進める。毎秒150標本相当、最大24,001点、描画DPRは最大1.75。細線の加算合成と先端の小さな光で発光を表し、重いブルームや床反射は使わない。WebGL2対応環境が必要。実機iPhone Safari、スクリーンリーダー、低性能端末の負荷測定は未検証。[確認画像](docs/harmonograph/README.md)を参照。

実装は `harmonograph.ts`（係数・軌跡・状態遷移）、`harmonograph-view.ts`（描画・UI）、`harmonograph-inspector.ts`（同じ係数から数式表示）、`harmonograph-guide.ts`（座標投影と成分図）に分ける。`main.ts` は作品選択とmount/disposeのみを担当し、既存作品の描画は `fractal-view.ts` へ移動した。作品切替時は描画ループ・イベント・ResizeObserver・GPUバッファ・テクスチャ・WebGLコンテキストを破棄する。既存の `fractal.ts` と `structures.ts` の数式計算・定義は変更しない。

### 動きの仕組みを見る（教材モード）

操作パネルの「動きの仕組みを見る」で、作品とは別の減衰なし・各方向1項の教材を開く。静止した時刻0から始まり、「再生」「一時停止」「0.25秒進める」「最初から」で確かめられる。停止中だけ時間送りができ、20秒で止まる。「最初から」は設定と段階を保ち、再生中なら再生も保って0秒へ戻る。

段階は「左右の往復」→「上下も加える」→「奥行きも加える」→「軌跡を残す」。これは見せる方向の順番で、点がx→y→zと順番に動く意味ではない。全方向を同じ時刻tで計算する。1は軌跡なし、2・3は直近約1.5秒、4は0秒からの蓄積を表示する。段階変更では時刻・設定を保つ。

教材の式は `x=A sin(ωt)`、`y=1.4 sin(t+π/2)`、`z=0.8 sin(2t+π/4)`。初期値はA=1.4、ω=1 rad/s。「xの往復の幅」は中心から端までの振幅A（端から端は2|A|）、「xの往復の速さ」は角周波数ωを変える。y・zは固定。設定変更では時刻を保って停止し、過去の線も新設定で計算し直す。数式の強調された数値も同じ係数に更新する。

初期の2次元教材は円になるが、値が範囲内に収まることと軌跡が閉じることは別。作品は各方向2項と減衰を含み、この教材そのものではない。「教材から作品へ」で違いを確認できる。

1・2は正面、3・4は斜めから表示し、後者はドラッグ・タッチ・視点ボタンで回転できる。「図形を確認」は明示的に図へ移動する。それ以外の段階選択で自動スクロールは行わない。「作品へ戻る」またはEscapeで、元の作品設定・視点・進行位置へ戻る。作品の時計は教材中に進まず、元が再生中なら再開する。ただし教材中にOSの「動きを減らす」を有効にした場合は元の位置で停止する。教材はOS設定に関係なく自動再生せず、設定を途中で有効にした際も停止する。

教材の計算と状態は `harmonograph-lesson.ts`、表示は `harmonograph-lesson-view.ts`。作品と共通の `evaluateAxis` で数式を評価し、同じ係数からMathMLを作る。軌跡は0.02秒間隔、最大1,001点。既存のrendererと描画ループを共有する。WebKitの再割当て後の空白を避けるため、描画バッファは作品を開いた時点の大きさを保ち、リサイズではCSSとカメラを追従させる。大きく拡大した場合は初期解像度によるぼけがあり、作品を再選択すると現在の画面寸法で確保し直す。

### 数理構造インスペクター

作品右側（モバイルでは作品下）の「パラメータ」「数式・構造」を切り替える。「数式・構造」では二分岐フラクタル、波動変形、合成の順序を確認できる。一般式と現在値の代入式を分け、調整中の値は**太字と背景**で強調する。スライダー側も同じ記号を用い、変更・初期値へのリセットに同期する。通常の数値は固定係数である。

### 使用数式と実装の対応

`src/fractal.ts` の実際の処理を正本とする。以下の数値は実装の固定係数であり、ユーザーが変更する初期値と区別する。

二分岐フラクタル（`generateTree` / 内部の `grow`）:

```text
Lₙ = L₀ × rⁿ                 L₀ = 1.15（固定）
θ_child = θ_parent ± α
xend = xstart + cos(θ_branch) × Lₙ
yend = ystart + sin(θ_branch) × Lₙ  z = 0
B = 2ᴰ − 1
```

根元は `(0, −2.4, 0)`。`n` は幹を0とする世代で `0 ≤ n < D`。`D` は幹を含む段数、`B` は枝数。各子枝は `heading + p.angle` と `heading - p.angle`、長さは `length * p.shrink` で生成する。子枝同士の開きは `2α`。有限深さで打ち切る自己相似な平面分岐木であり、無限反復した極限図形は計算していない。

`θ_parent`・`θ_child` は選んだ親枝とその子枝の方向角、`θ_branch` は座標を計算する枝自身の方向角（その `grow` 呼び出しの `heading`）である。親の呼び出しでの `heading` が `θ_parent`、子へ渡す `heading ± p.angle` が `θ_child` であり、子の呼び出し内ではその値が `θ_branch` になる。幹の `θ_branch` は固定の `π/2 rad`。同じ世代でも枝の方向角は異なり得るため、方向を世代だけで表す `θₙ` は使わない。一方、同じ世代の枝長は等しいため `Lₙ` の表記を維持する。

波動変形（`deform`）:

```text
φ = 2πd/λ − ωt
E(d) = 1 − exp(−0.8d)
x′ = x + A × E(d) × sin(φ)
y′ = y
z′ = z + 0.5 × A × E(d) × cos(φ)
```

| 記号 | Params / 意味 | 単位 |
| --- | --- | --- |
| D | depth / 幹を含む分岐の段数 | 段 |
| α | angle / 親枝からの方向変化 | rad |
| r | shrink / 子枝の長さの縮小率 | 無次元 |
| A | amplitude / 変位の振幅係数 | 座標単位 |
| λ | wavelength / 累積距離上の波長 | 距離単位 |
| ω | speed / 位相の時間係数 | rad/s |
| d | 変形前の根元から枝に沿った累積距離 | 距離単位 |
| t | アニメーション内の経過時間 | 秒 |
| φ | 位相 | rad |
| E(d) | 根元で0、距離とともに1に近づく包絡 | 無次元 |

`ω` は空間を進む速度そのものではない。`t` は一時停止中は進まず、1フレームの増分は既存実装どおり最大0.05秒。代入式でも `d`・`t`・`n` は未指定なので記号で残す。例として枝長は `Lₙ = 1.15 × 0.72ⁿ` になる。これは**正弦波による幾何学的変形**であり、物理的な波動方程式を数値的に解いたものではない。

### 合成方式

1. `generateTree` が平面上の枝の端点と始点の累積距離を生成する。
2. `sampleTree` が枝の始点・終点を `deform` に渡す。終点の距離は `dend = dstart + ℓ`、`ℓ` は `Math.hypot` で計算した変形前の枝長。再帰生成では `distance + length` を子枝に渡す。
3. 変形後の端点を `Float32Array` に格納し、Three.jsの線分として描画する。

毎フレーム元座標から変形し、前フレームの変形を累積しない。分岐点は座標と累積距離を共有し、浮動小数点丸めを除いて同じ変形を受ける。

### 既知の制約と今後の発展

数式表示は [MathML Core](https://www.w3.org/TR/mathml-core/) の上付き・下付き・分数等を使用する。追加の数式ライブラリは不要だが、MathML対応ブラウザが必要で、数学フォントや支援技術によって見た目・読み上げに差が生じ得る。旧ブラウザ向けの代替表示は未実装。スクリーンリーダーと実機タッチ端末による確認は未実施。

端点間を直線で結ぶため、枝の途中を波形の曲線として細分化しない。数式内の固定係数は生成実装に対応した説明データとして保持している。計算実装を変更するときは数式定義と整合テストも更新する必要がある。数式の任意入力・解析・実行は行わない。

今後は他作品からの構造定義の再利用、異なる構造の合成、Memo Nexus・Calculator Memoとの連携を検討する。汎用数式エンジンや大規模なプラグイン基盤は今回の対象外。

これは静的な枝分かれを数学的な正弦波で変形する試作品であり、物理的な波動方程式の解ではない。完成作品のSites展示、作品定義の永続保存、複合エンジンの一般化は後続課題。

### 数式ビジュアル解説（Issue #5）

「数式・構造」の各数式カードにある「図で見る」を押すと、選択カードの枠と作品側の補助図が対応する。もう一度押すか、作品下の「解説を解除」、Escapeで解除する。別の式を選ぶと切り替わる。Enter / Spaceでも操作可能。「図形を確認」は明示的に作品へ移動し、作品下の「選択中の数式へ」でカードへ戻れる。選択だけでは自動スクロールしない。

| 数式ID | 図で示す内容 |
| --- | --- |
| length | 変形前の全枝を世代別に着色。前／次の世代で端点の十字と枝長を確認 |
| heading | 幹と左右の子枝の代表例。白い親方向の延長から黄色の弧で各 α、子枝間は2α |
| count | 世代を手動で選択。2ⁿ本の端点の十字、D段と全枝数2ᴰ−1の対応 |
| endpoint-x / endpoint-y | 同じ代表枝の変形前のx／y成分を黄色の矢印で分解。残りの成分は青 |
| phase | 代表端点の十字と、その端点のφ mod 2πの位相計・時刻・sin / cos値 |
| envelope | 全端点でE(d)を十字の大きさと色で表示。大きさは包絡の指標であり、実際の変位量ではない |
| deform-x / deform-z | 代表端点の変形前（白）から対象軸成分だけを黄色の矢印で表示。残りの成分は青、変形後は黄色の十字 |
| deform-y | 代表端点の変形前後を同じy座標の線で接続し、Δy=0を数値表示 |
| distance | 根元から代表端点までの変形前の枝に沿った経路と枝長の和 |

構造の補助図にある灰色の全枝は変形前、通常の水色の作品は変形後。代表例の規則は全枝・全端点に適用される。変位ゼロでは矢印を十字で示す。正面からはz成分が投影上見えないので、ドラッグまたは「奥行きを回転」を使う。「拡大」「縮小」もキーボード・タッチで利用できる。回転後の画面の水平・垂直はモデルのx・y軸と一致するとは限らない。

通常の再生時刻だけを使い、説明専用の時刻は進めない。一時停止で作品・位相計・補助図も停止する。パラメータ変更では最新データから再計算。パラメータタブへの移動とリセットは解説を解除する。リセットは再生状態と視点を維持する。OSの「動きを減らす」では初期状態を停止にし、設定が途中で有効になった場合も停止する。利用者は「再開」を選べる。点滅や自動世代送りは使わない。

実装の追加先は `src/visual-model.ts`（ID対応、日本語説明、実データから補助線を作る純粋関数）と `src/visual-overlay.ts`（Three.js描画と説明欄）。親子関係・世代は既存の共有端点から導出するため、`fractal.ts` と `structures.ts` の計算・定義は変更していない。別作品への展開時は、その作品の数式IDと補助線モデルを追加し、inspectorのコールバックと描画アダプターを接続する。汎用プラグイン基盤は設けていない。

新機能の検証は `src/visual-model.test.ts` と `e2e/visual.spec.ts`。変更前の計算手順との座標・Float32Array比較、親子と累積距離、αの弧、成分矢印、位相の数値関係を確認する。E2Eは全11式の選択・解除、停止画像の不変性と解除後の画像復帰、キーボード、パラメータ、回転・ズーム・サイズ変更・再開・リセットを確認する。実機iPhone Safari、スクリーンリーダー、低性能端末での負荷測定は未検証。確認画像は `docs/visual-explanations/` を参照。
